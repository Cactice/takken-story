# 宅建study 時間・報酬設計 提案書(リサーチ結果)

前提: GAME_DESIGN.md(1年≒リアル1時間、試験15問・年1回・3ヶ月前応募、世代交代、資産1億)を踏まえ、文献ベースで「時間の刻み方」「報酬の出し方」「学習効果の担保」を具体化する。搾取的ダークパターン(課金圧、無制限FOMO)は除外し、学習継続に効く仕組みに絞った。

## 1. セッション長とループ設計

**推奨: 1セッション5〜10分、コアループ1周=2〜3分、1日1〜3セッション想定。**

根拠:
- **モバイルセッション研究(GameAnalytics系データ, Udonis まとめ)**: モバイルゲームのセッション中央値は4〜6分、カジュアル系は約4分。上位25%タイトルでも8〜9分。プレイヤーは「長く1回」ではなく「短く1日約4回」開く。→ 5分で必ず1つの達成(相談1〜2件解決+報酬)が完結する構造にすべき。
- **Hook Model(Nir Eyal, "Hooked", 2014)**: トリガー→行動→変動報酬→投資 の4段階が1セッション内で1周する必要がある。宅建studyでの対応: トリガー=住民の「!」アイコン/通知、行動=クイズ回答、変動報酬=報酬額のゆらぎ+住民の反応、投資=資産・知識度・住民との関係値が積み上がる。「投資」が次回セッションのトリガー(あの住民の続きの相談)を仕込むのが理想。

具体形: **「相談1件=約2分」を最小単位**にする。相談は「住民の状況説明(30秒)→クイズ1〜3問(1分)→解決演出と報酬(30秒)」。1セッションで2〜4件解ける。

## 2. 時間の刻み方: プレイ時連動を主、リアル連動を従に

**推奨: ゲーム内時計は「プレイ中のみ進む」方式(プレイ時連動)。リアルタイム連動は日次ボーナスと相談の"予約蓄積"だけに限定するハイブリッド。**

根拠:
- **Animal Crossing 型リアルタイム連動の分析(Game Developer 誌の任天堂インタビュー等)**: リアル時計連動は日課の習慣化に強い一方、「ログインしないと取り返しがつかない」ことが最大の弱点で、任天堂自身が緩和機能を追加している。本作は**年1回の試験と世代交代がある**ため、リアル連動にすると「寝ている間に試験を逃した/主人公が老いた」が起き、学習アプリとして致命的。→ 人生の進行はプレイ時連動が必須。
- **放置ゲー研究(Alharthi et al. "It Started as a Joke: On the Design of Idle Games", CHI PLAY 2019 / Eric Guan "Idle Game Design Principles")**: 待ち時間の価値は「戻ってきたら必ず何かある」こと。ただし優良な放置設計は**蓄積に上限(キャップ)を設ける**ことでFOMOを抑えつつ復帰動機を作る。

具体形:
- 主人公の年齢・カレンダー・試験はプレイ時間でのみ進行。
- オフライン中は「相談の予約」がリアル時間で溜まる(**上限3件**)。戻れば必ず解く相談があるが、溜め損ねのペナルティはゼロ。
- リアル1日1回の「町の朝イベント」(アポイントメント機構)でボーナス。

## 3. 報酬スケジュール: 固定+変動の二階建て

**推奨: 相談報酬=「固定基本料+確率変動ボーナス」。試験合格=大型固定ボーナス+成績連動。**

根拠:
- **変動比率強化(Skinner のオペラント条件づけ; Nagle et al., International Journal of Serious Games のシリアスゲーム実験)**: 変動比率スケジュールは固定比率より消去耐性が高く、シリアスゲームの実験でも変動比率+プレイヤー適応型の報酬は楽しさ・成績・プレイ継続意向を有意に高めた。→ 「基本料は必ず、上乗せ(ご祝儀、レア家具、住民からの紹介)は時々」。正答自体の報酬を運任せにしないこと(学習の随伴性を壊さない)。
- **目標勾配効果(Hull 1934; Kivetz, Urminsky & Zheng, JMR 2006)**: ゴールに近づくほど努力が加速する。→ 応用2点:
  1. **試験応募締切**を目標勾配の装置にする。「応募済み→試験まであと○ヶ月」を常時表示し、試験直前の3ヶ月(プレイ約15分)は模試イベント・復習相談を増やして"追い込み区間"を演出する。
  2. **資産1億**は遠すぎるので、中間マイルストーン(100万→1000万→3000万…)を刻み、進捗バーを常に見せる。世代交代直後は「先代からの引き継ぎ資産」で"押印済みスタンプ"効果を出す。
- **ストリーク設計(Duolingo の公開知見: 600回超のA/Bテスト、streak が retention を大幅に押し上げ、損失回避が約7日目から効く)**: streak は効くが、罰的にすると学習アプリでは離脱要因になる。**フリーズ(お守りアイテム)を月2個**配り、達成条件は「1日相談1件」と最低限にする。目標日数はユーザーに選ばせる(自己設定目標の方がコミットメントが強い)。

具体形:
- 相談正答: 基本報酬(難易度×固定額)+ 25〜30%の確率で1.5〜3倍ボーナス演出。
- 誤答: 報酬なしだが罰金なし。「後日また相談される」(=復習機会)に変換。
- 試験合格: 年収数年分の大型ボーナス+満点なら称号。不合格でも「経験値」的な小報酬で来年へ接続。

## 4. 学習効果との両立: 間隔反復×テスト効果

**推奨: 出題はリアル日数ベースの拡張間隔で再出題。試験=年次の総復習リトリーバル。**

根拠:
- **テスト効果(Roediger & Karpicke, 2006)**: 再読より「思い出すテスト」自体が長期記憶を作る。相談=クイズ形式は正しい設計。解説は回答後に必ず表示する(フィードバック付き検索練習)。
- **間隔効果(Cepeda et al., 2006 メタ分析; Cepeda et al., Psychological Science 2008 "temporal ridgeline")**: 最適な復習間隔は「テストまでの遅延の約10〜20%」。分散学習は集中学習の最大2倍効率。→ ゲーム内時間ではなく**リアル日数**で間隔を管理する(記憶はリアル時間で減衰するため)。

具体形:
- 各論点にライトナー式の箱(1日→3日→7日→14日→30日、リアル日基準)。誤答で箱を戻す。
- 再出題の皮: 同じ住民が「別の角度から同じ論点」で再相談に来る(丸暗記でなく転移を促す)。世代交代は「新主人公が学び直す」という自然な全論点リセット・再出題の物語装置として使える。
- 試験15問の構成: 直近1年に出た論点から10問+復習期限が来ている過去論点から5問。試験そのものを spaced retrieval にする。

## 5. 具体的推奨値まとめ

| 項目 | 推奨値 | 主根拠 |
|---|---|---|
| 1セッション想定 | 5〜10分(最小完結単位=相談1件2分) | モバイルセッション中央値4-6分 |
| 1年のプレイ時間 | **60分で維持(1ヶ月=5分)** | 1セッション≒1.5〜2ヶ月進む計算で違和感がない |
| 時計方式 | プレイ時連動(オフラインで人生は進まない) | Animal Crossing 型の弱点回避 |
| 相談イベント数 | **ゲーム内1ヶ月に2〜4件(≒2分に1件)** | セッション内で2-4件解ける密度 |
| 試験周期 | 年1回=プレイ約60分ごと(維持) | 適度な高頻度リトリーバル |
| 応募締切 | ゲーム内6月末応募→10月試験。締切1ヶ月前から住民が声かけ。未応募超過時は1回だけ「社長の口利き」救済 | 目標勾配効果+取り返し不能の回避 |
| オフライン蓄積 | 相談予約が最大3件までリアル時間で蓄積 | 放置ゲー研究のキャップ設計 |
| デイリー | リアル1日1回「町の朝」ボーナス(最初の相談1件が報酬1.5倍) | アポイントメント機構 |
| streak | 「1日相談1件」、フリーズお守り月2個、目標日数は自己設定 | Duolingo 知見+損失回避の非罰的運用 |
| 報酬 | 固定基本料+25-30%で変動ボーナス。誤答は無罰・再相談化 | 変動比率強化 |
| 復習間隔 | リアル日基準 1/3/7/14/30日のライトナー式。試験15問中5問は復習枠 | Cepeda 間隔効果+テスト効果 |

**注意: 「1年=60分」は学習間隔の管理には使わない。** ゲーム内時間は物語とモチベーションの装置、記憶の間隔反復はリアル日数で別管理、という二重時計がこの提案の核。
