## 第1世代: ほのぼの村移住編(原点と基礎)
**舞台**: ありきた村 / **目標**: **資産1000万円**

自然豊かな「ありきた村」に移住してきた主人公**主一**。村の不動産屋「禿鷹社長」に拾われ、宅建の基礎から仕事を教わる。のんびりとした雰囲気の中、村人たちの小さな住まいの悩みを解決しながら、地域密着型の不動産事業を引き継ぎ、村の発展の礎を築く。

**学習方針**: 基礎中心。わかりやすさ・馴染みやすさ最優先。

## 第2世代: 都会の洗礼と野望編(スピードと誘惑)
**舞台**: 黒会市(くろかいし) / **目標**: **資産1億円**

過疎化が進む村に限界を感じた2代目**主二**は、大都会「黒会市」で独立し、自分の店を **黒主不動産** と名づける。しかし都会の不動産業界はルールが厳しくライバルも強力。そんな中、面倒見はいいがグレーな手法も厭わない24歳のコンサルタント「**海沢カイル**」と出会う。彼の助言で大金を手にするが、「誇大広告」や「重要事項説明の義務違反」など、徐々に宅建業法のタブーに足を踏み入れていく。

**学習方針**: 宅建業法の禁止事項を「やってしまう側」から学ぶ。

### 第2世代のオープニング
1. 黒会市に着いた主人公に、**海沢が気さくに話しかけてくる**
2. 主人公が「なぜ都会に来たのか」を説明する(村の限界、独立の決意)
3. 海沢が**自分の所有するぼったくり物件**を親切ごかしに紹介し、ここからゲームが始まる
4. **所持金300万円スタート**(村で貯めた資金を持って出てきた)

### 海沢のポジション
**第2世代のメンター役=海沢**(第1世代の禿鷹社長と同じ立ち位置)。
ただし**信用できないメンター**である点が決定的に違う。
- 海沢の「教え」には、グレーな手法や業法違反すれすれの内容が混ざる
- プレイヤーはまず**ぼったくり物件を掴まされる側**として、重要事項説明や誇大広告の論点を身をもって学ぶ
- 「メンターの言うことが正しいとは限らない」という構造自体が、第2世代の学習装置になる

## 第3世代: 過去の遺産と村の謎編(サスペンス)
**舞台**: ありきた村 / **目標**: **資産3000万円**

1世代目(祖父**主一**)と仲が良く、村で育った3代目**主三**。しかし主一が急死。それをキッカケに、村の古株「**見沼家**」と、数年前に越してきた「**鈴木家**」の間で、おじいちゃんの残した土地や境界線を巡るドロドロの権利争い(民法・相続トラブル)が勃発する。プレイヤーは2代目禿鷹社長(子孫)の事務所に身を寄せ、彼らと協力しながら、証拠集めや法廷バトルを通じて事件の裏に隠された真実を暴く。

**学習方針**: 民法(相続・共有・境界・時効・登記)を事件の証拠として使う。

### 第3世代のオープニング
1. **主一(第1世代の主人公=主三の祖父)の葬儀**から始まる。村で育った主三は、慕われていた祖父を見送る
2. 通夜の席で、**見沼家と鈴木家が土地の境界を巡って言い争いを始める**。主一が遺した土地が火種になっている
3. 見かねた**2代目ハゲ田(禿鷹ハゲル)**が主三を事務所に引き取り、「調べるぞ。証拠を集めろ」と告げてゲームが始まる
- **メンター役**: 2代目ハゲ田(禿鷹ハゲル)。父(主二)ではなく、祖父(主一)の代からの付き合いがある家の人間
- **所持金**: 主一の遺産の一部を相続して**500万円**スタート(相続そのものが最初の学習題材になる)
- **決着のあと**: 禿鷹ハゲルは禿鷹不動産を主三に渡す(「わたしはね、預かっていただけですのでね」)。**禿鷹家が商売を手放す瞬間**で、第4世代以降の村長路線はここから始まる
- **トーン**: 静かな緊張。ユーモアは禿鷹ハゲルのとぼけた物言いに逃がす

### 構造:稼ぐことが、そのまま捜査になる
第3世代は**「宅建の知識が捜査の道具そのもの」**である世代。勉強したから解けたのではなく、
**解くために必要だったのが宅建の知識だった**という順序で書く。

- **仕事 = 手がかり**。相談・仲介・重説を1件こなすと、その過程で必ず事件の断片(`clue`)が1つ手に入る
- **転出が主軸**。この世代は他より**転出者が多い**。村を出ていく人に理由を聞くと、その理由自体が宅建の論点であり、
  同時に六十年前の記憶が一つずつ出てくる(花屋の借地・パン屋の造作)
- **転入は「前に住んでいた新しい町」からの避難民**。契約の期限を理由に住まいを失った人たちが、
  ありきた村に流れ着く。彼らの**引越しの希望の形で、追い出され方が語られる**
  (「借りるのではなく買いたい」「期限のない家がいい」)。第5世代の白夜村への伏線だが、
  **第3世代では白夜村の名も海沢の名も出さない**
- **資産3000万円の達成と真相の解明が、同じ行動で進む**。金策と捜査を別作業にしない

### どんでん返し
> あらすじは [story-all.md](story-all.md)、イベント一覧は [events-by-generation.md](events-by-generation.md)。

**柵をずらしたのは、親切で柵を立て直した鈴木家であり、誰一人として悪意がなかった。**

主一のノート、最後の一冊の最後(`ev-minpo-dairi` の `clue`):
> 見沼さんと鈴木さんの境。三十年前の台風で柵が倒れ、鈴木さんが立て直してくれた。
> ご厚意だった。誰も悪くない。
> ただ、あの柵は、元の場所より少しこちらに寄っている。
> 二人ともそれを知らない。私だけが知っている。
> 私が売った土地だ。私が始末をつける。

- 六十年前、見沼タネゾウと鈴木タケオは**握手で境界を決め、書面を作らなかった**(「柵で決まっとる、紙は要らん」)
- 三十年前の台風で柵が倒れ、**鈴木家が親切で立て直した**。前と同じ場所のつもりで、数十センチずれた
- 以来三十年、両家とも**それを本当の境界だと信じて**暮らした。片方は「昔からここだ」と言い、もう片方も「ずっとここだった」と言う。**二人とも嘘をついていない**
- 主一だけが知っていて、**自分で始末をつけようとしていた**。ノートの日付は**死ぬ三日前**。間に合わなかった
- 悪意ある犯人はいない。**書いて残さなかった見沼タネゾウ**、**調べる前に動いた鈴木タケオ**、**親切で柵を立て直した鈴木家**、**顔を立てて黙った主一**——善意と思い込みが三十年ぶん積み重なった食い違い
- 決着は法律で付く。**登記は本物**、**鈴木家の取得時効も本物**。だからこそ「どちらが正しいか」ではなく「どう終わらせるか」の話になる

**「三日前」が二つ重なる。** 主一がノートに「私が始末をつける」と書いた三日後に主一は死に、**同じ週に山へ仮登記が入っている**(`ev-toki-ho`)。主一が動き出したのを知って、町の人間が先に席を取った——という読み方ができる形にしておく。

黒会市の男(仮登記・無権代理・無許可の盛土・囲い込み)は**答えではなく圧力**。争いが続くかぎり山は安いままだと知っていて、争いを維持しに来ている。だから**争いを終わらせること自体が防衛策になる**。
裏山の盛土は最後まで村の中では解決しない。禿鷹ハゲル「あれはね、村の話じゃないんですよ。……**町の話**です」——第4・第5世代へ渡す。

### 白夜村の伏線(第5世代へ)
- 冬野ソウ・冬野アカリ夫妻は「前に住んでいた**新しい町**」を、**借家の期間満了**で追い出されて村へ来た。悪いことは何もしていない
- 冬野アカリ「あの町はね、住んでる人のことを**数字で見る**の」——町の名も、海沢の名も出さない
- 傷は**要望の形**で出る:「借りるのではなく買いたい」「二度と期限で追い出されない家がいい」
  (`dislikedFeatures`: 定期借家・借地・再開発予定)
- 悲惨にしない。**ありきた村に来てほっとしている人たち**として書く。「不便だけど、人が人として扱われる」
- 争う両家の横で「土地でもめられるのは、土地がある人だけよ」と言う人がいる、という温度差を作る
- 第5世代で海沢と対峙する理由が思想の対立ではなく、**「この人たちを追い出したのはお前だ」**という具体的な怒りになる

## 第4世代: 没落からの大逆転編(都市開発・再建)
**舞台**: 黒会市 / **目標**: **資産3億円**

村で暮らしていた3代目**主三**が、都会で潰れた会社を買う。**黒主不動産**——2代目**主二**が黒会市で興し、宅建業の「**欠格事由**」に該当して免許を取り消された会社である。主三はそれを村の**禿鷹不動産**と統合し、**黒鷹不動産**(黒会市の「黒」+禿鷹の「鷹」)とした。4代目**主四**は、この統合された会社を継ぐところから始まる。

**会社は買えても、免許は買えない。**看板は掛け替えられたが、免許だけは承継されなかった。債務のほうはそのまま付いてくる。正当な「法令上の制限(都市計画法など)」の知識を駆使して都会の厄介なトラブルを解決し、正々堂々と10億の巨大プロジェクトを成功させる。

**学習方針**: 免許制度(欠格事由・**免許の非承継**・新規免許)から入り、法令上の制限へ。

### 第4世代のオープニング
1. **主三が倒産寸前の黒主不動産を買う**場面から始まる。主二が業法違反で免許を失い、看板と債務だけが残っていた会社である
2. 村の禿鷹不動産と統合して **黒鷹不動産** に名を改める。主四はその会社を継ぐ
3. ところが**免許が下りない**。看板は掛け替えられても、免許だけは買えなかった
4. **免許の下りていない事務所で、債権者の電話が鳴っている**——ここが一日目。父・主三が「ここから正面突破でやり直す」と宣言し、**後輩の鈴木ピンクも合流**してゲームが始まる
- **メンター役**: 父・主三(第3世代=プレイヤーが前の世代で操作していたキャラ)
- **所持金**: **マイナスからの再建**。50万円スタート(全世代で最も少ない)。買収で引き継いだ債務の返済が最初の目標
- **トーン**: 逆境からの立て直し。悲壮になりすぎず、負けん気とユーモアで押す

#### 核心の論点: 免許は承継されない(宅建業法76条)
免許を取り消された業者は「**取引を結了する目的の範囲内**」でのみ、なお宅建業者とみなされる。
残っているのは前の契約の後始末をする資格だけで、**免許そのものは会社と一緒に移らない**。
新しい看板で新しく商売をするなら、**新規に免許を取り直す**しかない。

> 主三「会社は買えた。債務も買った。免許だけが買えん。あれは会社に貼ってある紙じゃないんだ」

**主二は「金で買えるものは全部買った」男だった。**その男が唯一買えなかったものから第4世代が始まる、という対比になっている。
第4世代の主題「近道はもうやった」に、条文が裏づけを与える形。

- **学習の軸**: 欠格事由(なぜ免許を失ったのか) → **免許は承継できない**(76条) → 新規免許の取得 → 法令上の制限
- **役員の欠格事由(5条1項2号・12号)には踏み込まない。**「免許は承継できないので取り直す」の一点に絞る

### 禿鷹家の転換点
第3世代で禿鷹不動産を主三に返した禿鷹家は、**第4世代以降、不動産業から離れる**。
四代目**禿鷹ハゲ子**(禿鷹ハゲルの孫)は第3世代で村に残り、商売を降りた禿鷹家を**村の運営側(村長)**へ移す。第4世代の黒会市に禿鷹家は出ない。
商売を手放したから、村のために動く時間ができた家である。

## 第5世代: 新幹線誘致と村の最終決戦編(集大成・総力戦)
**舞台**: **ありきた村** / **目標**: **資産1億円**

会社は巨大に成長したが、最大の壁が立ちはだかる。2代目をそそのかした海沢カイルはとうに死んでいる。だが黒会市と隣町を繋ぐ「**新幹線誘致プロジェクト**」を動かしているのは、海沢カイルの孫娘 **海沢リリー**——会ったことのない祖父のノートを暗記して育った人物だった。

**海沢家の過激な思想**(海沢カイル→海沢セシル→海沢リリーと受け継がれた): 「古い村(ありきた村)など潰してしまえ。自然も歴史も無駄だ。完全管理された人工リゾート『白夜村』こそが完璧な都市である」という、過激なスクラップ&ビルド(破壊的開発)の思想。

委員会は「人口が多く、発展している方に新幹線を通す」と宣言。プレイヤー(**主五**)は最後の力を振り絞り、見沼家、鈴木家、禿鷹家など、これまでの世代で絆を深めたキャラクターたちを総動員。**村を代表して動くのは村長になった禿鷹家**で、主五は不動産屋として契約をまとめる側に立つ。「ありきた村」の自然を残しつつ、**空き家バンクやリノベーション(農地法・税制優遇)**を駆使して村の人口を爆発的に増やし、海沢リリーの野望を打ち砕く感動のフィナーレ!

**クリア後**: 新幹線で村と市を即座に移動できるようになる。

### 第5世代のオープニング
1. **新幹線誘致の記者会見**から始まる。委員会が「人口が多く発展している方に通す」と宣言する
2. 壇上に**海沢リリー**が現れ、祖父の口癖そのままに白夜村の完璧さを語り、ありきた村を「畳むべき村」と切って捨てる
3. 主人公は村と市の両方を背負う立場として立ち上がる。**これまでの世代で縁を結んだ全員に声をかけるところ**からゲームが始まる
- **メンター役**: 特定の一人ではなく、**歴代の仲間たち**(見沼家・鈴木家・禿鷹家の当代)が持ち場ごとに助言する
- **役割分担**: 決めるのが**禿鷹家(村長)**、空き家バンクなど窓口の実務を走るのが**村役場の岸和田ポンポン**、契約を成立させるのが**主五の事務所**。三者が重ならないように書く
- **所持金**: 会社は巨大に成長している。**5000万円**スタート。ただし目標は10億なので桁が足りない
- **トーン**: 総力戦。熱く、真っ直ぐに。ユーモアは仲間との掛け合いで

## キャラクター設計のポイント
- **海沢家**: 「ただの悪人」ではなく「効率と利益だけを極限まで追求した不動産屋のなれの果て」。宅建ゲームのラスボスとしての説得力
- **見沼家 vs 鈴木家**: 3世代目でいがみ合った両家が、5世代目で村を守るために協力する胸熱展開
- **禿鷹家**: 各世代に子孫が登場し、主人公家系と並走する。第3世代で会社を主三に返し、**第4世代以降は不動産業を離れて村の運営側(村長)へ**。大きくならないことを選び続けた家の着地
- **新幹線**: 街づくりゲームの最終目標としてのワクワク感
