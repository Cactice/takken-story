# 共通のルール

## 書き方

- **1イベント3〜5行。**大事な回でも増やさない
- **一行を短く。**読点で三つ繋げない
- **含みを持たせない。**察させる書き方は使わない
- **強い場面ほど短く。**説明した瞬間に弱くなる。数えるのは読者の仕事
- **ナレーションは使わない。**思ったことは本人が口に出す。状況説明はその場の誰かに言わせる
- **主人公も喋る。**主一〜主五として直接言わせる。ナレーションで代弁しない
- 《主人公の説明》は**2行まで**

## 指導役

世代ごとに変わる。4拍子(住民が困る → 指導役が分解する → 主人公が説明する → 礼を言われる)は共通。

| 世代 | 指導役 | 声の芯 |
|---|---|---|
| 1 | 禿鷹禿ゲ田 | 「新人」。「〜だ」「〜しろ」。ぶっきらぼうだが面倒見がいい |
| 2 | 海沢カイル | 敬語。惜しみなく教える。締めは「で、どうします?」 |
| 3 | 禿鷹ハゲル | 父ゆずり。角が一枚取れている。手柄にしない |
| 4 | 主三(父) | 多くを語らない。答えを先に言わない |
| 5 | 鈴木ピンク | 44歳。「〜っす」。絶対に責めない |

締め方は回ごとに変える。教えてやる / お前が言え / 黙って見てる / 自分で調べろ / そもそも挟まない。

## kind の付け方

その回で、案内できる空き物件が1つ増えるか / 1つ埋まるか。

| kind | 条件 |
|---|---|
| 転入 | その回の直後に内見が始まる |
| 転出 | その人が本当に去り、住んでいた家が空きに戻る |
| 恋愛 | 親密度が上がると想い人が家を見に行きたいと言う |
| 悩み | 上記以外 |

## 恋愛

**各世代1本、相手は旅人の美一〜美五。**恋愛イベントにしか登場しない。**別れの回を兼ねる。**
**求める家の条件は、その人の弱点とそのまま重なる。**
性別は主人公の逆になるので、**男女どちらでも読める書き方**にする(一人称は「わたし」、語尾は「〜です」)。

## 家ごとの喋り方

| 家 | 芯 |
|---|---|
| 海沢 | 先輩。教え方がうまい。**儲けに直結しないことは平気で間違え、恥じない。**儲けに直結することは間違えない |
| 黒瀬 | **上から目線。**「教えてやる」ではなく「知らないのか」。決まりを守るのは決まりだから |
| 葉山 | **困っている場面でも「王家の血筋なんですが」を混ぜる。**誰も信じないが事実 |
| 都倉 | **全員、語尾に「ぽ」。**喋り方そのものは一人ずつ違う。題は連番のシリーズ |

## 転出した人は、次の世代の舞台で再会する

| 出ていく | 次に会う | どうなっているか |
|---|---|---|
| 第1世代 **都倉オヤジ**が四人の子を連れて村を出る | 第2世代 黒会市 | 業務停止を食らって店を畳む。四人の息子は誰も不動産をやらなかった |
| 第1世代 **白石オリビア**は村に残る | 第2世代 黒会市 | 本家の兄・白石ジョージに手紙を書き、主二が食事に呼ばれる |
| 第3世代 **岸和田ヤチン**が二棟を売って村を出る | 第4世代 黒会市 | ビルを買い、テナントを追い出せずに揉める |
| 第3世代 **桜井家の孫**が修行に出る | 第5世代 | 村へ戻り、曾祖母のオーブンで焼く |
| 第2世代 **都倉ヨンナン** | 第3世代 村 | 街を出て、村の空き家を買う |
