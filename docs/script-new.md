# 全イベントの台本(再構成版)

世代ごとに**指導役が変わる**。同じ4拍子(住民が困る → 指導役が分解する → 主人公が説明する → 礼を言われる)を、5通りの声で書く。

| 世代 | 指導役 | 声の芯 | 締め方 |
|---|---|---|---|
| 1 | 禿鷹禿ゲ田 | 「新人」。「〜だ」「〜しろ」。ぶっきらぼうだが面倒見がいい | 「教えてやる」 |
| 2 | 海沢カイル | 敬語。「〜ですよ」「〜でしょう?」。惜しみなく教え、決して怒らない | 「で、どうします?」(必ず選ばせる) |
| 3 | 禿鷹ハゲル | 父ゆずり。「新人」「〜だ」。角が一枚取れているだけ。手柄にしない | 「……お前が言え。わたしが言うと年寄りの説教になる」 |
| 4 | 主三(父) | 多くを語らない。答えを先に言わない。「近道はもうやった」 | 黙って野帳の該当ページを開く |
| 5 | 鈴木ピンク | 44歳。「〜っす」。まっすぐ優しい。絶対に責めない | 「自分も分かんなかったっす。一緒に見ましょう」 |

  《のちに》 ガストン「祭りな、ほんまにやることになってもうた。田中さんが畑の隅を貸してくれる言うてな。ええ人や。」

# 第2世代 ｜ 黒会市(誘惑) ｜ 1045年〜

全18件 — 人生 1 / 転入 3 / 転出 4 / 悩み 8 / 恋愛 2

**指導役は海沢カイル。**この世代の骨格そのものである。

カイルは**いい人**である。教え方がうまい。惜しみなく教える。約束は守る。後輩をかばう。誰も彼を悪く言わない。
実家は地方の小さな不動産屋で、看板を下ろす日を高校生のときに見ている。**故郷を救えなかった男が、二度と同じことを起こさないために効率を選んだ。**だから熱い。義憤に近い。
条文を誰よりも正確に知っていて、**どこに線が引いてあるかも正確に知っている。**そのうえで、線の手前をぎりぎりまで使う。
教えたあとは必ず「**で、どうします?**」と主二に選ばせる。計算ではない。**自分で決めさせるのが誠実だと本気で思っている。**

村からは禿ゲ田の手紙が届く。教えはしない。一行だけ書いてある。**1052年から返事の間隔が空き、1055年以降、手紙は一通も来ない。**

通し線は A:カイルの頼みが一段ずつ重くなる / B:ホチキは捨てない / C:ハガネが見ている。
本筋は、**主二が正しい答えを言い続けたまま、少しずつ何かを手放していく十二年**である。
