# 共通のルール

世代ごとに**指導役が変わる**。同じ4拍子(住民が困る → 指導役が分解する → 主人公が説明する → 礼を言われる)を、5通りの声で書く。

| 世代 | 指導役 | 声の芯 |
|---|---|---|
| 1 | 禿鷹禿ゲ田 | 「新人」。「〜だ」「〜しろ」。ぶっきらぼうだが面倒見がいい |
| 2 | 海沢カイル | 敬語。惜しみなく教え、決して怒らない。締めは「で、どうします?」 |
| 3 | 禿鷹ハゲル | 父ゆずり。角が一枚取れている。手柄にしない |
| 4 | 主三(父) | 多くを語らない。答えを先に言わない |
| 5 | 鈴木ピンク | 44歳。「〜っす」。絶対に責めない |

**1イベント5〜7行。**《主人公の説明》は2行まで。
**締め方は回ごとに変える。**教えてやる / お前が言え / 黙って見てる / 自分で調べろ / そもそも師弟のやりとりを挟まない。

## kind の付け方

**判定はこれだけ。**その回で、案内できる空き物件が1つ増えるか / 1つ埋まるか。

| kind | 条件 | ゲーム上 |
|---|---|---|
| 転入 | **その回の直後に内見が始まる**(家を探しに来た人だけ) | 空きが1つ埋まる |
| 転出 | **その人が本当に去り、住んでいた家が空きに戻る** | 空きが1つ戻る |
| 恋愛 | 親密度が上がると想い人が家を見に行きたいと言う。**内見が起きる** | 契約で埋まり、去るとまた空く |
| 悩み | 上記以外。誰かが街を出た台詞が入っていても、空きが増えないなら悩み | — |

## 恋愛

**各世代1本、相手は旅人の美一〜美五。**恋愛イベントにしか登場しない。**恋愛イベントが別れの回を兼ねる**。
**求める家の条件は、その人の弱点とそのまま重なる。**内見のたびに弱さが出る。
性別は主人公の逆になるので、**台詞は男女どちらでも読める書き方**にする(一人称は「わたし」、語尾は「〜です」)。

## 家ごとの喋り方

| 家 | 芯 |
|---|---|
| 海沢 | 先輩。面倒見がよく教え方がうまい。**儲けに直結しないことは平気で間違え、訂正されても恥じない。**儲けに直結することは一度も間違えない |
| 黒瀬 | **上から目線。**「教えてやる」ではなく「知らないのか」。決まりを守るのは正義感ではなく、決まりだから |
| 葉山 | **困っている場面でも「王家の血筋なんですが」を混ぜる。**上品にふざける。誰も信じないが事実 |
| 都倉 | **全員、語尾に「ぽ」。**家じゅうの癖で本人たちは変だと思っていない。喋り方そのものは一人ずつ違う。題は連番のシリーズ |

## 転出した人は、次の世代の舞台で再会する

舞台が 村→都会→村→都会→村 と交代するので、**出ていった先が次の世代の舞台**になる。
**去る回の台詞に必ず行き先を残す。**

| 出ていく | 次に会う | どうなっているか |
|---|---|---|
| 第1世代 **都倉オヤジ**(禿鷹不動産の三人目)が四人の子を連れて村を出る | 第2世代 黒会市 | 1045年に街角で一度すれ違い、1054年に業務停止を食らって店を畳む。**四人の息子は誰も不動産をやらなかった** |
| 第1世代 **白石オリビア**は村に残る | 第2世代 黒会市 | 本家の兄・白石ジョージに手紙を書く。街に出た主二を、白石家が食事に呼ぶ |
| 第3世代 岸和田ヤチンが二棟を売って村を出る | 第4世代 黒会市 | その金でビルを買い、**今度は自分が居座るテナントを追い出せずに揉める** |
| 第3世代 桜井家の孫が修行に出る | 第4世代 → 第5世代 | 狭いワンルームで家賃と通勤時間を計算し、二度またいで村へ戻る |
| 第2世代 都倉ヨンナン | 第3世代 村 | 騙されかけた人が街を出て、村の空き家を買う |

## 1017年9月 ｜ [恋愛] 一年だけ借りる部屋

minpo-chintai ｜ `rom-bi-1`(新規)

**この回の直後に内見が始まる。**美一が求めるのは「**いつでも出られる部屋**」。
弱点(長くいる場所を作らないと決めている)が、そのまま物件の条件になっている。

  - 美一「ここ、まだ地図にないんです。……あ、いえ。今日はその話じゃなくて。」
  - 美一「数ヶ月のつもりで来たんですけど、まだ描き終わらなくて。宿代がもう厳しいんです。」
  - 美一「一年だけ部屋を借りたいんですけど、そんな短い契約ってできるものなんですか。」
  - 美一「……一年って言っておけば、一年で必ず出られますよね。それが、いちばん大事なので。」
  - ハゲタ「新人、そこは素人が必ず読み違えるところだ。……俺は表におる。二人で話せ。」

  《主人公の説明》
  - 建物を1年未満で借りると、期間の定めがないものとして扱われます。1年ちょうどなら定めとして有効です。
