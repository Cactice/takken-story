# 単一の正典(Single Source of Truth)

いま物語のデータが `content/`(70件のJSON)、`docs/script-new-gen1〜5.md`(108件の台本)、
`docs/story-all.md`、`docs/story-all-subplot-household.md`、`docs/household-plan.json` に散っている。
同じ事実が5箇所にあり、直すたびにずれる。**これを1つに畳む。**

読み物(あらすじ・台本・人物一覧・小説)は**全部ここから生成する**。手で書くのはここだけ。

## ファイル構成

```
story/
```

生成物(`docs/` 以下)は全部使い捨てにする。`script-dump.md` / `characters.md` /
`story-all.md` / `novel.md` は `story/` から作り直せるので、手で触らない。

## 1. 家系 — 苗字が色を決める

**苗字に色か素材の手がかりが入っている。**服の色はそこから引く。
だからプレイヤーは名前を見ただけで、画面のどの人かが分かる。

| 家系 | 由来 | 服の色 |
|---|---|---|
| 主 | (主人公家。無彩) | 生成り |
| 禿鷹 | 鷹 | 焦茶 |
| 海沢 | 海 | 濃紺 |
| 見沼 | 沼・土 | 深緑の土色 |
| 鈴木 | 木 | 木肌の褐 |
| 桜井 | 桜 | 淡紅 |
| 水瀬 | 水 | 水色 |
| 岸和田 | 岸・砂 | 砂色 |
| 田中 | 田 | 稲の黄緑 |
| 白石 | 白 | 白 |
| 織部 | 織部焼(緑釉) | 深緑 |
| 冬野 | 冬・雪 | 雪の白青 |
| 都倉 | 蔵(なまこ壁) | 白と黒 |
| 葉山 | 葉 | 若草 |
| 安西 | 紙 | 生成りの灰 |
| 黒瀬 | 黒 | 黒 |
| 美 | (旅人。どこにも属さない) | 旅の紅 |

```json
{
  "id": "minuma",
  "name": "見沼家",
  "cloth": { "base": "#4a5d3a", "accent": "#8a7a4f" },
  "hair": {
    "male":   { "strands": 8,  "length": 0.28, "part":  0.4, "spread": 0.5, "curl": 0.1, "tie": null, "bangs": 0.3, "stiff": 0.7 },
    "female": { "strands": 12, "length": 0.75, "part": -0.2, "spread": 0.3, "curl": 0.4, "tie": 0.35, "bangs": 0.6, "stiff": 0.3 }
  },
  "story": "村の第一号。「土地は減らすもんじゃない」だけが三代受け継がれ…",
}
```

- `cloth.base` … 服の面。`cloth.accent` … 帯・襟・袖口
- `hair.male` / `hair.female` … **家系内で共通。**兄弟は同じ形になる

### 髪 — 32通りを値で出す

17家 × 男女 = **34の髪型**。一つずつ描かず、8つの値の組み合わせで作る。

| 値 | 範囲 | 何が変わるか |
|---|---|---|
| `strands` | 4–16 | 房の本数。少ないとさっぱり、多いと重い |
| `length` | 0.1–1.2 | 頭の高さに対する長さ。0.15=坊主 1.0=腰まで |
| `part` | -1〜1 | 分け目。0=中央 |
| `spread` | 0–1 | 横への張り出し。爆発頭かぺったりか |
| `curl` | 0–1 | 毛先の巻き |
| `tie` | null / 0–1 | 結び目の高さ。0.9=高いポニーテール null=結ばない |
| `bangs` | 0–1 | 前髪の量 |
| `stiff` | 0–1 | 布シミュの硬さ。**同じ形でも揺れ方が変わる** |

**揺れ方まで家系の個性にする。**黒瀬は `stiff` を高く(硬い・ほとんど動かない)、
水瀬は低く(よく揺れる)。歩き出したときに、誰の家の人かが動きで分かる。

房は根本を固定した4〜6点の鎖。重力とダンピングだけの Verlet で回す。
**32通り全部が同じコードで動く。**個別の実装はゼロ。

## 2. 人物 — 姿は年齢から計算する

**身長と腰の曲がりは持たない。年齢から導く。**データを増やさずに、
子供は小さく、老人は縮んで曲がる。

```
身長  = 0.55 + 0.45 * min(age/18, 1) - max(0, (age-60)) * 0.002
腰    = max(0, (age - 55) / 45)          0=まっすぐ 1=大きく曲がる
```

服の形は `gender` から引く(女=裾が広い / 男=裾が直線)。
**色は家系、形は性別、丈と姿勢は年齢。**それだけで誰か分かる。

```json
  "gender": "male",
```

## 3. イベント — セリフと問題と過去問を1つに

台本(`script-new-*.md`)と問題(`content/**.json`)が別々なのをやめる。
**1イベント1オブジェクト。**

```json
{
  "id": "ev-minpo-jiko",
  "year": 1085, "month": 8,
  "kind": "trouble",
  "title": "8歳の夏に、柵は動いた",
  "summary": "鈴木ソラが「クヌギは柵の向こうにあった」と証言する",
  "cast": ["minuma-yesu", "suzuki-sora", "hageta-hageru"],
  "lines": [
    { "who": "minuma-yesu", "text": "鈴木さんとこの柵、うちの畑に食い込んどる。" },
    { "who": "suzuki-sora", "text": "……立て直した、だ。台風の年に、村じゅうの柵が倒れた。" },
    { "who": "shu-3", "text": "20年、誰も文句を言わなかった。それが効きます。" }
  ],
  "topicId": "minpo-jiko",
  "quiz": {
    "question": "他人の土地を20年間占有し続けた。所有権はどうなるか。",
    "choices": ["…", "…", "…"],
    "answer": 1,
    "explanation": "…",
    "diagram": { "type": "timeline", "labels": ["…"] }
  },
  "thanks": "…",
  "later": "…",
}
```

- `who` は**キャラid**。表示名は `characters.json` から引く。
  台本で「リク」と書いて誰か分からなくなる問題が消える
- **主人公も `shu-1`〜`shu-5` として `lines` に並ぶ。**
  「主人公の説明」を別の入れ物(`playerLines`)に分けない。
  台本を上から読めば会話がそのまま流れる
- 過去問の指しは**イベントではなく論点が持つ**。同じ論点のイベントで共有できる。
  **問題文は持たない。**中身は `kakomon/json/`(gitignore)にある

### 構想画面では元の問題も見える

`kakomon` の指しから `kakomon/json/` の本文を引いて、**構想画面にだけ**並べる。
「この会話は、実際にはこう出題される」を横に置いて確かめられる。

- 読み込みは `import.meta.glob` ではなく**開発サーバ限定**にする(`import.meta.env.DEV`)
- 本番ビルドには入らない。リポジトリにも入らない

## 見た目(構想画面)

Florence のようなミニマリズム。**線は細く、面は少なく、動くのは髪だけ。**

- 髪は**布のシミュレーション**で揺れる。長さは家系の `hair` で決まる
- 服は**面ひとつ**。色は家系、形は性別
- **身長と腰の曲がりで年齢が分かる。**顔は描かない(点二つ程度)
- 背景は無地に近い。人物と、そのとき喋っている一行だけ

`/debug` を「構想を見る画面」に作り替える。ゲームのシステム(内見・試験・時間経過)は
一度全部外し、**イベントと人物を眺めるだけの画面**にする。
