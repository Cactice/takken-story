## 1. 診断 — なぜ通しで読むと辛いのか

### (1) 前振りがない。その行が初出でその行が事件

```
1015年8月 [悩み] はじめての祭りでけが人
  ガストン「村ではじめての秋祭りでな、やぐら組むのに人を雇うたんや。」
  ガストン「そしたら、その若いのが材木を落としてもうて…。」
```
祭りの存在・雇用・会場提供が、**全部この4行で初めて出てきて、同じ4行で壊れる**。読者は誰の何が壊れたのか分からないまま解説を聞かされる。施主の言う「唐突」はこれ。

### (2) 入り方が同じ。岸和田ガストンだけで5回

```
「坊、えらいこっちゃ。ちょっと聞いてくれや。」        (1016/8 祭り)
「坊、田中さんの母屋を買う約束をしてな。」            (1016/9 手付)
「おう坊、聞いてくれや。うちの店子の先生が…」        (1017/2 壁紙)
「なあ坊、聞いてや。うちのアパートの101号室に…」    (1020/2 息子夫婦)
「坊、ちょお教えてくれや。古いほうのアパートを…」    (1022/5 納税通知)
```
5回とも「坊」+「聞いてくれ」+ 困りごと。**キャラが立っているのではなく、フォーマットが立っている。**

### (3) 締めも同じ。70回とも上司が「教えてやる」で終わる

```
ハゲタ「…教えてやる。」「…答えろ。」「…言ってやれ。」
```
住民が困る → ハゲタが分解する → 主人公が説明する → 礼を言われる。**この4拍子が60回連続する。**種別の内訳が 悩み86% なので、構造上そうなるしかない。

### (4) 同じネタを二度やっている

```
1045/6 [悩み] 徒歩5分の事務所   ハガネ「私も測ったもの。十二分。」   論点 gyoho-kokoku
1047/3 [悩み] 徒歩五分の嘘      ハガネ「わたし、歩いてみたの。9分だった。」論点 sonota-keihin
```
**同じ相手(海沢カイル)に、同じ人(黒瀬ハガネ)が、同じ突っ込みを2年後にもう一度している。**カイルの返しまでほぼ同じ(「駅の敷地の端からなら5分」)。

### (5) 人が出入りしないので、いるのかいないのか分からない

```
1017/2 ガストン「うちの店子の先生が、診療所の近くに家を見つけて出ていきよってな。」
1020/2 ガストン「今の店子さんとの契約、来月で二年の満了でな。」→ 店子は白石オリビア
```
**1017年に出ていったはずのオリビアが、1020年に同じアパートにいる。**転出イベントが存在しないので、去ったのか残ったのか台本上どこにも書かれていない。

### (6) 一人が世代を独占する

第4世代13本のうち **9本が都倉チョーナンJr.**。「がっはっは」の人が世代の7割を持っている。第2世代18本は**全部が悩み**で、大半が海沢カイル案件。

### (7) 物語に一行も噛んでいない回がある

```
1138/5 [悩み] 川跡の低地に家を建てるか
  ポンポン「川沿いの低い畑、あそこを宅地にできませんか?」
  リク「…待った。あそこは昔、川が流れてた跡だ。」
  ポンポン「…わかりました。」
```
出て、教わって、引き下がる。**誰の関係も変わらないし、誰も何も失わない。**同種の回の洗い出しは §6-b。

## 4. 人間ドラマの通し線

イベント単発ではなく、**前の回を受けて次の回が動く**線を各世代に2〜3本。

### 第1世代

| 線 | 誰と誰 | 動き |
|---|---|---|
| **A. 無知が赦されていく** | 岸和田ガストン ↔ 田中ポッポ | 転入(何も知らずに二棟建てた) → 祭りでポッポにけがをさせる → 手付を打ってやめる(ポッポは怒らない) → **壁紙でポッポが三日口をきかない** → 息子夫婦(今度は自分から相談に来る) → 納税通知(まだやる)。**「知らなかった」が「聞くようになった」に変わるまでを6本かけて描く** |
| **B. 誰も紙を書かない村** | 見沼タネゾウ ↔ 水瀬・鈴木 | 保証人を口約束で済まそうとする → 花屋の底地に契約書が一枚もない → **最終回、鈴木家との境界を握手で決める。**プレイヤーは3回目にして「またか」と思う。その「またか」が第3世代の全部になる |
| **C. 書かれなかった遺言** | 織部シルビア | 転入(六ヶ月しばりの紙を勧められて怖くなる) → 遺贈という手があると教わる → **「書くと、本当に終わりみたいでしょう」で書かない** → 第5世代、誰も相続しない家になる |

### 第2世代

| 線 | 誰と誰 | 動き |
|---|---|---|
| **A. カイルの要求が一段ずつ重くなる** | 海沢カイル ↔ 主二 | 黙っていた(看板料) → 手順を飛ばせ(モデルルーム) → 順番を変えろ(許可前広告) → 法の上限を超えろ(手付800万) → **渡すべき紙を渡すな(37条)** → 証拠を消せ(帳簿)。**毎回「合理的でしょう?」で終わるが、内容が違法に寄っていく** |

## 5. 転入・転出をどう使うか

**原則**: 転入=**その人がこの町に置いた最初の一手**、転出=**置いていくもの / 残していくもの**。引っ越しの世話は器で、中身は必ず「誰かの人生の区切り」にする。

### 転入(16本)の型を3つに分ける

| 型 | 中身 | 例 |
|---|---|---|
| **来る** | 生活を始める側の最初の契約 | 見沼(保証人)/ 冬野(全部先に説明する)/ 桜井の孫(都会のワンルーム) |
| **迎える** | 受け入れる側が困る | 岸和田の息子夫婦(先住者を追い出す)/ 鈴木ハウス(受け皿を建てる)/ 畑を宅地に / パンで来た人たち |
| **戻る** | 出ていった家が帰ってくる | 都倉ヨンナン(騙された街を出る)/ 葉山ヒメカ(会見を聞いて) |

### 転出(13本)は必ず「理由」を先の回で見せておく

| 去る人 | 世代 | 理由がどこで蒔かれているか |
|---|---|---|
| 佐藤(有資格者) | 1 | 開幕の1本前。**辞める理由=村から人が減る**が、そのまま第3世代の主題になる |
| 白石オリビア(アパート退去) | 1 | 転入イベント「二棟建ててしまった人」でガストンの空室が示されている |
| 前の借主(夜逃げ) | 2 | 開幕で借りた事務所そのもの。**主二が座っている椅子が、誰かの失敗の跡** |
| 引渡しを果たさなかった売主 | 2 | ハガネの「最近そういう話が多いの」 |
| 同期の店 | 2 | 「一件だけのつもりだった」。主二が同じ台詞を言える位置にいる |
| 三号棟の四世帯 | 2 | 増築部分は主二がまとめた物件。**自分の客が黙って出ていく** |
| 主一 | 3 | 第1世代15年ぶんの働き。葬式で全員が同じことを言う |
| 岸和田家の孫 | 3 | 第1世代で二棟が空室だったこと |
| 水瀬リオン | 3 | 第1世代「花屋の下の土地」の続き。60年後 |
| 桜井メープル | 3 | 第1世代「丘の上のカフェ」の同一人物。オーブンを倉庫へ |
| 岸和田ビルのテナント | 4 | 第3世代で孫が二棟を売った金 + 前年の区画整理 |
| 白夜村へ移る母 | 4 | 第5世代の敵役がそこで育つ |
| 織部家(誰も出ていかない) | 5 | **第1世代で「遺言はまだ書いておりませんのよ」と言った回**。120年越しの回収 |

**「1世代しか出ない家をつくらない」への対応**: 転出13本のうち**10本が、前の世代で登場済みの家**。転出は世代をまたぐ接着剤として使うのがいちばん効く。
