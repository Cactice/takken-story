# 台本の書き方

**会話を読み終えた時点で、答えが立っていること。**これがこの台本の唯一の仕事である。

いまの台本は、読んでも答えが分からない。初見のプレイヤーは必ず外す。
外して解説を読むのは勉強であって、遊びではない。
**会話の中で手がかりを配り、プレイヤーに組み立てさせる。**

---

## 1イベントの形

**問題の前は4行。問題のあとは1〜2行。**これが目安である。
長い回でも前5行・後2行を超えない。読むのに疲れる回は、それだけで飛ばされる。

```
    4行   状況 → 間違った直感 → 手がかり → 物語の一行
  [図]    論点の解説から借りる
  [問題]
  1〜2行   主人公が答えを言い、指導役が一言足す
```

| 行 | 役目 |
|---|---|
| 1 | **具体の状況。**誰が、何を、いくらで、何平米で。数字を必ず出す |
| 2 | **間違った直感。**誰かが自信を持って言う。これが誤答の選択肢になる |
| 3 | **手がかり。**分かっている人が、決まりを**普通の言葉で**言う |
| 4 | **物語の一行。**その人が何を抱えているか。ここが無いとただの授業になる |

4行目は説明に使わない。物語のために使う。3行で足りるなら3行でよい。

問題のあとは**主人公が答えを言い、指導役が一言足す**。それで終わる。
用語は落とさないが、言い換えは1回だけでよい。

## 手がかりの配り方

**答えそのものを言わない。**言った瞬間に問題が消える。

```
✗ ハゲル「専任媒介の期間は3ヶ月までです。6ヶ月と書いても3ヶ月になります。」
        → 選択肢を読む必要がない

○ ハゲル「1社に絞る契約は、長く縛れないことになっとります。」
  シルビア「じゃあ6ヶ月って書いた紙は、破り捨てるってこと?」
  ハゲル「……いえ。長すぎる分だけが縮みます。紙は生きたままです。」
        → 「無効になるのは契約全体か、超えた分だけか」が争点だと分かる。
          数字(3ヶ月)は問題文と選択肢の側にある
```

配るのは**判断の軸**であって、数字ではない。
「何で決まるか」を会話で渡し、「いくつか」を問題で問う。

## 誤答は、誰かが口にしたことにする

3つの選択肢のうち、**間違い2つは会話に出てきた誰かの言い分**であること。
プレイヤーが「さっきタネゾウさんがそう言ってたな。でもハゲルさんが違うと言った」と
たどれる。**選択肢を消す作業が、会話を思い出す作業になる。**

## 数字は会話に出す。ただし答えの数字は出さない

- 敷地300平米、建蔽率60%、容積率200% → **会話に出す**(問題を解くのに要る)
- 「3ヶ月まで」「2割まで」「5日以内」 → **出さない**(それが答えだから)

## 声を守る

`story/characters.json` の `personality` `catchphrase` `smallTalk` を必ず読むこと。
説明のために人格を崩さない。**分からない人は分からないまま質問し、
知っている人は知っている顔で答える。**急に全員が賢くなってはいけない。

指導役は世代で変わる。

| 世代 | 指導役 | 話し方 |
|---|---|---|
| 1 | 禿鷹禿ゲ田 | 乱暴で短い。「いいか」「〜だぞ」。主一を「新人」と呼ぶ |
| 2 | 海沢カイル | 丁寧で有能。「合理的でしょう?」。**儲けに関係ないことは平気で間違える** |
| 3 | 禿鷹ハゲル | 住民に敬語、主人公に「新人」。手柄を自分のものにしない |
| 4 | 主三(父) | 息子に教える。多くを言わない |
| 5 | 鈴木ピンク | 「〜っす」。短い。ダジャレを言い、人を本気で褒める |

## 触ってよい場所

`lines` と `quiz` **だけ**。
`id` `year` `month` `kind` `title` `topicId` `thanks` `later` は動かさない。

`lines` の要素:

```json
{ "who": "hageta-hageru", "text": "……新人。あんたなら、どっちだと思う。" }
{ "who": "shu-3", "text": "…", "role": "teach" }
```

`role: "teach"` は**答えたあとに主人公が言う確認**である。
ここで初めて法律用語を出す。会話は普通の言葉、確認で用語。**具体から抽象へ**の順を守る。
`who` は必ず `story/characters.json` にある id か `shu-1`〜`shu-5`。

## 問題は本試験に寄せる

`kakomon/json/*.json`(リポジトリには入っていない)に過去15年分がある。
`story/topics.json` の `kakomon` に、その論点で実際に出た問の指しが入っている。
**本物がどこで引っかけるかを見てから問題を書く。**

ただし**問題文をそのまま持ってこない。**
簡単な言葉に言い換え、正しい用語は丸括弧で添える。

```
本試験  「宅地造成等工事規制区域内において行われる盛土であって、
          当該盛土をした土地の部分に高さ1メートルを超える崖を生ずることとなるもの」
この台本 「土を盛って、1メートルより高い崖ができる工事(盛土)」
```

引っかけ方だけを借りる。文章は自分で書く。

## 言葉の高さを、会話と問題で変える

**会話はできるだけやさしい言葉で。問題は正しい用語で、少し難しくてよい。**

試験は用語で問うので、問題文をやさしくしすぎると本番で読めなくなる。
だが会話までやさしさを捨てると、頭に入らない。**分けるのが正解である。**

| | 言葉 |
|---|---|
| 会話 | 「1社に絞る契約」「土を盛って崖ができる工事」「先に本人へ言ってくれ、と返せない」 |
| 問題 | 「専任媒介契約」「宅地造成等工事規制区域内の盛土」「催告の抗弁権」 |

そして**難しい用語を出すときは、指導役に説明させる。**1行でよい。

```
ハゲタ「専任媒介ってのは、1社にだけ頼む契約のことだ。ほかに頼めねえ代わりに、
        向こうも本気で動く。それだけの話だぞ」
カイル「催告の抗弁権、という言葉があります。先に本人へ請求してくれ、と言える権利です。
        連帯保証には、これが無い」
```

この1行があると、問題文で用語に出会ったときに引っかからない。
**用語を教えるのは指導役の仕事**で、住民の仕事ではない。住民はやさしい言葉のまま困っていてよい。
