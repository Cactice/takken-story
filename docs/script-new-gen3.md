# 第3世代 ｜ ありきた村(ミステリー) ｜ 1075年〜

全18件 — 人生 1 / 転入 2 / 転出 4 / 悩み 9 / 恋愛 2

**指導役は禿鷹ハゲル(60歳)。**初代・禿ゲ田の息子。父ゆずりの「新人」「〜だ」だが、角が一枚取れている。
住民には敬語、主人公にはぶっきらぼう。**手柄を自分のものにしない。**
締めは「……お前が言え。わたしが言うと年寄りの説教になる」を軸に変奏する。

村から人が出ていく年。**転出4本が同じ世代に並ぶこと自体が物語**である。
通し線は A:弱い当主の赦し / B:出ていく村 / C:三日前(死んだ主一が世代を通して動いている)。

年齢の対応: 主一 75歳で死去(1000年生)。鈴木ソラは1028年に8歳(1020年生)なので1084年に**64歳**。
水瀬リオン76歳、桜井メープル72歳、見沼ヌカベエ当主、見沼ワカバ・鈴木リクは若手。

## 1076年10月 ｜ [転出] アパートを畳んで出る

  - ヤチン「岸和田です。ガストンの孫です。……祖父の話、聞いてますか。」
  - ヤチン「木造二棟、二十部屋。何も無い村に建てて、空室だらけで毎日ここに通ってたそうですね。」
  - ヤチン「六十年経ちました。……いま何部屋埋まってると思います? 三部屋です。」
  - ヤチン「売ります。二棟とも。その金で黒会市に出ます。あっちならビルが買える。」
  - ハゲル「……岸和田さんの二棟がなくなると、この村で貸せる部屋は一つも無くなりますな。」
  - ヤチン「じゃあ誰が埋めるんですか。埋める人がいないから出るんですよ。」
  - ヤチン「それで、税の話です。祖父の代からの持ち物なので、いつ買ったかも分からない。」
  - ヤチン「短く持ってた土地は税が重いと聞きました。うちはどうなるんですか。」
  - ハゲル「……新人。持っとった年数で税率が変わる。数え方に癖があるやつだ。」
  - ハゲル「お前が言え。この人はもう決めてしまっとる。せめて、正しい額で出ていってもらおう。」

  《主人公の説明》
  - 売って出た利益(譲渡所得)は、持っていた期間で税率が変わります。
  - 5年を超えていれば長期譲渡で、所得税15%・住民税5%。5年以下の短期なら所得税30%・住民税9%です。
  - 期間の数え方に癖があって、**売った年の1月1日時点**で5年を超えているかで判定します。六十年なら文句なく長期です。

  《お礼》 ヤチン「長期ですか。……そこだけは祖父に感謝します。長く持ってただけですけどね。」
  《のちに》 ハゲル「二棟、更地になった。……あの人、間違ってはおらん。六十年、誰も埋めてやれんかった。それだけだ。」
