## この世代の目的 ｜ 祖父の汚名を晴らす

**1075年2月、15歳の主三の目の前で、祖父の主一が連れていかれる。**
容疑は**重要事項の不実告知**。見沼家と鈴木家のあいだの境界を、偽って説明した、というもの。
**疑いが晴れないまま、勾留中に急死する。**汚名を着たまま遺されたものを、孫が引き継ぐ。

主三が働くのは金のためではない。**祖父の名前を戻すため**である。

**1本目は、連れていかれるところだけ。**説明も、事情も、その場では出さない。

### 事件の構造

```
容疑  主一は境界を偽って説明した(重要事項の不実告知)
        ↓
事実  見沼家と鈴木家の柵は、たしかにずれている
      主一の説明とも食い違っている
        ↓
真相  台風の年、倒れた柵を鈴木家が親切で立て直した
      同じ場所のつもりで数十センチずれた。誰も測っていない
        ↓
結論  主一が説明した当時の境界は正しかった
      柵が動いたのは、そのあとである。嘘は一つもない
```

**境界の事件を解くことが、そのまま祖父の無罪の証明になる。**
決着は1085/8。**鈴木ソラの「クヌギは柵の向こう側だった」が、唯一の証拠。**
