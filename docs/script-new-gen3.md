  - うちの祖父は、この村を出た人です。理由は聞いていません。
  - 出ていった家のことは、残った人はあまり話しませんね。
  - 空き家って、外から見ると家なんですよ。

  《親密度6〜》
  - 見沼さんに祖父の名前を出したら、黙られました。
  - 残るのが正しいとも、出るのが正しいとも思っていません。
  - あなたは、どちらの側なんですか。……いえ、いいです。

  《親密度14〜》
  - 祖父はこの村を捨てたことになっています。
  - 出ていった人にも理由があったはずなんです。聞ける人が、もういない。
  - ……両方の言い分が分かると、どちらの味方にもなれないんですよ。

  《親密度24〜》
  - あなたは残る人ですね。迷ってすらいない。
  - 家は、決めた人のものになるんですね。
  - わたし、まだどこにも名前を書いたことがないんです。

  《家を見に行きたい》
  - 借りる部屋を見せてもらえませんか。買うのは、まだ決められないので。
  - 村の側でも街道の側でもない場所がいいです。
  - 祖父の家は直さずに置いておきます。

  《内見中》
  - (良) ここ、どちらからも同じくらい遠いですね。いい距離です。
  - (良) 借りるだけなら決められます。返せる約束は、こわくないので。
  - (悪) 見沼さんの畑が見えますね。……毎日見ていたら、村の側になってしまいます。
  - (悪) 買うんですか。買うと、ここの人になりますよね。
  - (中) どちらもいいと思います。……決めていないのと同じですね。

  《告白 / 旅立ち》
  - 祖父が出ていった理由、結局わかりませんでした。
  - でも、出ていく気持ちのほうは少しわかりました。
