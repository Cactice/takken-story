# 第3世代 ｜ ありきた村(ミステリー) ｜ 1075年〜

全20件 — 人生 2 / 転入 3 / 転出 2 / 悩み 12 / 恋愛 1

共通の書き方(指導役・kind・家ごとの喋り方)は [script-new.md](script-new.md) の冒頭を参照。
**目標2000万+事件解決 / 所持金500万 / この世代で増える稼ぎ方 = 収益物件**(禿鷹家に教わる)。

**指導役は禿鷹ハゲル(60歳)。**初代・禿ゲ田の息子。住民には敬語、主人公には「新人」。
父より角が一枚取れている。**手柄を自分のものにしない。**
締めは「……お前が言え。わたしが言うと年寄りの説教になる」を軸に変奏する。

通し線は A:弱い当主の赦し / B:出ていく村 / C:三日前。

**この世代は禿鷹家が商売から降りる世代。**人生イベント2本が対になっている。
**1089/3「鍵を返す日」= 会社を返す。1089/5「預かっていた物件」= 収益物件を渡す。**
どちらも「わたしはね、預かっていただけですのでね」で渡される。**譲るのではなく、預かっていたものを返す。**

**恋愛は美三1本のみ。美三は恋愛イベントにしか出ない。**告白と旅立ちが同じ回。

年齢: 主一75歳で死去。鈴木ソラは**1015年10月に8歳**(1007年生)なので、証言の1085年に**78歳**。柵の握手から**七十年**。
水瀬リオン76歳、桜井メープル72歳(夫婦)、美三18歳(1075年時点)。

**1イベント5〜7行。**《主人公の説明》は2行まで。

## 1078年9月 ｜ [恋愛] 祖父が出ていった家

toki-ho ｜ `rom-bi-3`(新規)

**この回の直後に内見が始まる。**美三が求めるのは「**どちらにも決めなくていい部屋**」。

  《主人公の説明》
  - 相続で不動産を取得したら、取得を知った日から3年以内に相続登記を申請する義務があります。
  - 放っておくと名義が何代も前のままになって、売るときに全員の同意が要ります。空き家が動かなくなる理由の一つです。

  《お礼》 美三「三年。……三十年、誰も出さなかったわけですね。」 美三「わたしが出します。出せる立場ではあるので。」
  《のちに》 美三「登記、通りました。……祖父の名前を消す書類に、自分の名前を書きました。変な気分です。」

  《親密度0〜》
  - うちの祖父は、この村を出た人です。理由は聞いていません。もう聞けません。
  - 出ていった家のことは、残った人はあまり話しませんね。悪口も言わない。ただ話さない。
  - 空き家って、外から見ると家なんですよ。誰も住んでいないだけで。

  《親密度6〜》
  - 見沼さんに、祖父の名前を出したら黙られました。怒ってはいないんです。ただ黙る。
  - 残るのが正しいとも、出るのが正しいとも思っていません。……そこが、たぶん私の弱いところです。
  - あなたは、どちらの側なんですか。……いえ、答えなくていいです。

  《親密度14〜》
  - 祖父はこの村を捨てたことになっています。祖父の側の話は、誰も聞いていません。
  - 出ていった人にも、理由があったはずなんです。それを聞ける人が、もういない。
  - ……両方の言い分が分かると、どちらの味方にもなれないんですよ。

  《親密度24〜》
  - あなたは残る人ですね。迷ってすらいない。……うらやましいです。
  - 家って、決めた人のものになるんですね。迷っている人には、名義がつかない。
  - わたし、まだどこにも名前を書いたことがないんです。今回のを除けば。

  《家を見に行きたい》
  - 借りる部屋を見せてもらえませんか。……買うのは、まだ決められないので。
  - 村の側でも、街道の側でもない場所がいいです。どちらかに寄ると、決めたことになるので。
  - 祖父の家は、直さずに置いておきます。住むと、答えを出したことになるでしょう。

  《内見中》
  - (良) ここ、どちらからも同じくらい遠いですね。……いい距離です。
  - (良) 借りるだけなら決められます。返せる約束は、こわくないので。
  - (悪) 見沼さんの畑が見えますね。……毎日見ていたら、たぶん村の側になってしまいます。
  - (悪) 買うんですか。買うと、ここの人になりますよね。……それは、まだ。
  - (中) どちらもいいと思います。両方いいと言うと、決めていないのと同じですね。分かっています。

  《告白 / 旅立ち》
  - 祖父が出ていった理由、結局わかりませんでした。三年いて、わかりませんでした。
  - でも、出ていく気持ちのほうは、少しわかった気がします。……わたしが今そうなので。
  - あなたは残る人です。わたしはどちらにもなれない人です。それだけの話です。
  - 家は残していきます。名義は直しました。……いつか誰かが住めるように。
  - ……住むのが、あなたでもいいです。それだけ言って帰ります。
