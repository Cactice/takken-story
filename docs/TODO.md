## やったこと

### 作り直した土台
- **`story/` の9ファイルを唯一の正典にした。**`content/` の148ファイル、
  `docs/` の手書き20本、`src/` のゲームシステムを全部消した。
  同じ事実が5箇所にあって、直すたびにずれていた
- 確認画面だけを残した。**物語 / キャラクター / 論点**の3つ

### 台本
- **104件すべてを「会話だけで答えが立つ」形に書き直した。**
  手がかりは「何で決まるか」を配り、「いくつか」は問題で問う。
  誤答2つは会話に出てきた誰かの言い分にする
- 問題の無かった53件に問題を書いた。**104/104**
- 正解の位置を散らした（第4世代は28件中21件が選択肢1だった）
- 恋愛イベント5件を削除。共有（`minpo-kyoyu`）の回を新規に1件追加
- 行の種類を `role` で表す。`quiz`（ここで問う）/ `figure`（ここに図）

### 図
- **図の型を5つにした。**関係・時間軸・段の表・断面・分かれ道。
  1種類だと、どの論点も同じ絵になって頭に残らない
- アイコンを `▭` `¥` のような文字記号から**線画のSVG 28種**に
- **物語の図は論点の解説から借りる。**`{ "role": "figure", "use": 0 }` と書くだけ。
  実体は `story/lessons/` にしかないので、二重管理が消えた
- 借りられている図を、その回の会話に合わせた（人物・数字・言い回し）

### 人の絵
- 色＝家系、形＝性別、丈と姿勢＝年齢。**顔は描かず、動くのは髪だけ**
- 髪は8つの値から34通り。硬さが揺れ方を変えるので、
  **黒瀬の髪は動かず、水瀬の髪は遅れて流れる**
- 40歳から白髪とシワ。腰の曲がりに合わせて首も傾く
- 男は例外なく逆三角形。まつ毛は女性だけ

### 過去問
- **OCRをやめ、貼りテキストから構造化し直した。**16回800問すべて完全
- 正解番号は出題元が公表している正解番号表から。推測は一つも無い
- 令和3年12月の問23が中国語の「问」で書かれていて、
  そのままだと問22が問23を丸ごと飲み込む壊れ方をしていた
- 物語には近い3問、論点には転がして3問。**答えは選んでから出す**

### 画面
- URLで直接開ける。`/monogatari/<イベントid>` `/ronten/<論点id>` `/jinbutsu`
- 物語と論点を相互にリンク
- スマホでは一覧と詳細を切り替える（PCは今のまま）

## 気をつけること

- **`laws/*.json` を消さない。**「過去問にこう書いてあるから正しい」を防ぐ唯一の手段。
  区分所有法は令和7年法律47号（2026-04-01施行）で決議要件が変わっていて、
  **過去問の記述をそのまま使うと間違って覚える**
- **過去問の本文をリポジトリに入れない。**著作権がある。`kakomon/` と `laws/*.txt` は除外済み
- **掛け合いを1行に潰さない。**字数は減るが、面白さも一緒に消える
