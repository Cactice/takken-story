  《のちに》 美一「一年の部屋、借りました。窓から柵が見えます。地図に描き足しました。」

  《親密度0〜》
  - ここからあの柵まで、二百三十歩でした。
  - 道に名前がないと、絵図に書きようがないんです。
  - 村の人はみんな「あの木の手前」で通じるんですよね。うらやましい。

  《親密度6〜》
  - あなたの歩き方、村の人と同じになってきましたね。
  - この村、来年にはもう形が変わってますよ。
  - ……今の、褒めたつもりだったんですけど。

  《親密度14〜》
  - 長くいる場所を、作らないと決めてるんです。
  - 描き終わったら次へ行きます。ずっとそうしてきました。
  - ……この村、描き終わるのが遅いんですよね。

  《親密度24〜》
  - 家って、どういう気持ちで買うものなんですか。
  - 窓から同じ景色を毎朝見るって、飽きないんですか。
  - あなたのいる場所を、地図の真ん中にしてしまいました。

  《家を見に行きたい》
  - 部屋を見せてもらえませんか。長く借りない前提で。
  - 窓は要ります。景色が描けないと、ここにいる意味がないので。
  - 荷物は行李ひとつです。広い部屋は持て余します。

  《内見中》
  - (良) 窓が大きいですね。ここに机を置いたら、村の北側が全部描けます。
  - (良) 一年で出られるんですよね。……そう聞くと落ち着きます。
  - (悪) 二年契約ですか。二年後の自分の場所を、わたしは決められません。
  - (悪) 広いですね。広い部屋にいると、荷物が増えるんですよ。
  - (中) 悪くないです。悪くないんですけど、決め手がなくて。

  《告白》
  - 絵図、描き終わりました。四年かかりました。
  - 描き終わったら次へ行くと決めていました。決めたのはわたしです。
  - ……この村を、描き終えたくなかったです。
  - 絵図は置いていきます。道の名前は全部わたしがつけました。
