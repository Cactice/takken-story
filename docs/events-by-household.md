# 世帯ごとの物語

**一族の六十年を縦に読む。** 世代で切るより、家ごとに追ったほうが変化が見える。
あらすじは [story-all.md](story-all.md)。

- 🔗 = 世代をまたぐ家。**この家が多いほど物語に厚みが出る**
- 単発 = 1世代しか出ない家(→ 末尾の一覧)
- 「どんな話か」は住民の最初のひとこと。〈 〉は分野(権利/業法/法令/税その他)
