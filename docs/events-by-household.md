# 世帯ごとの物語 — 設計の作業台

**一族の六十年を縦に読む。** 世代で切るより、家ごとに追ったほうが変化が見える。
あらすじは [story-all.md](story-all.md)。

このファイルは **これから何を作るかを設計する場所** で、実装済みイベントと未実装の計画が同じ表に並ぶ。

- 「どんな話か」列 = イベントJSONの `summary`(出来事の説明。セリフの引用ではない)
- 〈 〉は分野(権利/業法/法令/税その他)
- ✅実装済 = `content/gen*/events/` にJSONがある / *📝計画* = まだ無い。斜体
- **移動の型** = その家が村と都会をどう行き来するか。移動そのものが宅建の題材になる

| 型 | 何を語るか | 題材 |
|---|---|---|
| 村→都会 | 夢のために出ていく。親元を離れる | 初めての賃貸、保証人、狭小物件、定期借家 |
| 都会→村 | 疲れて/追われて戻る。Uターン | 空き家バンク、相続した実家、農地転用、譲渡所得 |
| 村に留まる | 根を張る。土地を守る | 相続、境界、借地、固定資産税 |
| 都会に留まる | 都会が性に合う | 区分所有、住み替え、住宅ローン |
| 村→都会→村 | 出て、戻る。一族で円環が閉じる | 修行先の狭小賃貸、Uターン、造作買取 |
| 都会→白夜村 | 管理された人工の街を選ぶ | 統計、地価公示、区分所有 |
| 白夜村→村 | 人工の街に追われて/疑って村へ | 定期借家、空き家バンク |
| 絶える | 跡継ぎがなく消える | 空き家、相続人不存在 |

**型は家に1つではなく、系統(枝)ごとに持つ。** 同じ親に育った兄弟が違う場所を選ぶ家があるため。
第1・3・5世代=ありきた村、第2・4世代=黒会市。**どの世代に出るかで、その人がどこに住んでいるかが決まる。**
枝の型と登場世代の舞台が食い違うと、このスクリプトはエラーで止まる。

> このファイルは `node scripts/gen-household-doc.mjs` で生成される。
> **手で書いた設計(移動の型・計画行)は [household-plan.json](household-plan.json) にある。** そちらを編集すること。
> 計画行を実装したら content にJSONを足し、household-plan.json の `planned` から消す。

> **あらすじ**
>
> **紙を扱う家である。**書く人、確かめる人、受け付ける人。五代のどこを切っても、主家のすぐ隣に安西の誰かが一人いる。

第1世代、村に一冊しかない台帳を書いていたのがこの家の先代だった。誰が何をいつ持っているかを、村でただ一人書き留めていた人である。第2世代、二十六歳の安西メイが主二の事務所の事務員をしている。数字と書類に几帳面で、おかしいと思ったことは相手が誰でも口に出す。海沢カイルの言うことを鵜呑みにしないと最初に決めたのが彼女で、モデルルームの開設に待ったをかけ、契約後の書面が買主に届いていないと指摘し、三千万の家に八百万の手付は取れないと言った。古い紙は捨てろと言われたときは、協会の黒瀬テツに保存年数を確かめてから、捨てなかった。

第3世代、十二歳下の妹の安西ルミは四十四歳の弁護士になっている。隣町から村へ通い、感情の高ぶった当事者の間に静かに割って入って「登記だけで決まる話ではありません」と言う。柵の位置、祖父の死の三日前の仮登記、同じ家の二重譲渡。誰も悪者にしないまま解いた。姉が書類を守り、妹が法廷に立つ。

第4世代、安西ルミの息子の安西ハジメは三十五歳、黒会市役所の都市計画課にいる。**開発許可の窓口である。**八百平米の分譲に許可が要るか、区画整理中の土地は使えるのか、防火地域で見積もりが倍になるのはなぜか。免許を取り直して立ち直っていく黒鷹不動産の過程を、彼は窓口から全部見ていた。淡々としていて、業者を試すような質問をする癖がある。

> **あらすじ**
