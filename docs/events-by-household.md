# 世帯ごとの物語 — 設計の作業台

**一族の六十年を縦に読む。** 世代で切るより、家ごとに追ったほうが変化が見える。
あらすじは [story-all.md](story-all.md)。

このファイルは **これから何を作るかを設計する場所** で、実装済みイベントと未実装の計画が同じ表に並ぶ。

- 「どんな話か」列 = イベントJSONの `summary`(出来事の説明。セリフの引用ではない)
- 〈 〉は分野(権利/業法/法令/税その他)
- ✅実装済 = `content/gen*/events/` にJSONがある / *📝計画* = まだ無い。斜体
- **移動の型** = その家が村と都会をどう行き来するか。移動そのものが宅建の題材になる

| 型 | 何を語るか | 題材 |
|---|---|---|
| 村→都会 | 夢のために出ていく。親元を離れる | 初めての賃貸、保証人、狭小物件、定期借家 |
| 都会→村 | 疲れて/追われて戻る。Uターン | 空き家バンク、相続した実家、農地転用、譲渡所得 |
| 村に留まる | 根を張る。土地を守る | 相続、境界、借地、固定資産税 |
| 都会に留まる | 都会が性に合う | 区分所有、住み替え、住宅ローン |
| 村→都会→村 | 出て、戻る。一族で円環が閉じる | 修行先の狭小賃貸、Uターン、造作買取 |
| 都会→白夜村 | 管理された人工の街を選ぶ | 統計、地価公示、区分所有 |
| 白夜村→村 | 人工の街に追われて/疑って村へ | 定期借家、空き家バンク |
| 絶える | 跡継ぎがなく消える | 空き家、相続人不存在 |

**型は家に1つではなく、系統(枝)ごとに持つ。** 同じ親に育った兄弟が違う場所を選ぶ家があるため。
第1・3・5世代=ありきた村、第2・4世代=黒会市。**どの世代に出るかで、その人がどこに住んでいるかが決まる。**
枝の型と登場世代の舞台が食い違うと、このスクリプトはエラーで止まる。

> このファイルは `node scripts/gen-household-doc.mjs` で生成される。
> **手で書いた設計(移動の型・計画行)は [household-plan.json](household-plan.json) にある。** そちらを編集すること。
> 計画行を実装したら content にJSONを足し、household-plan.json の `planned` から消す。

## 主家 ｜ 第1・2・3・4・5世代 ｜ 実装0件 + 計画0件

主人公の家系。ゲーム内で主人公は「あなた」で名前は画面に出ない。ドキュメント上は世代番号をそのまま名にして 主一〜主五 と呼ぶ。命名規則(苗字=漢字+名前=カタカナ)の唯一の例外

| 系統 | 移動の型 | 登場世代 | どういう枝か |
|---|---|---|---|
| 初代主一(1000年生)→二代目主二(1030年生)→三代目主三(1060年生) | **村→都会→村** | 1・2・3 | 主一が村で始め、主二が黒会市へ出て、主三が祖父の死で村へ戻る |
| 三代目主三→四代目主四(1090年生)→五代目主五(1120年生) | **村→都会→村** | 3・4・5 | 主四が免許取消で黒会市へ落ち、主五が村へ帰る。他の家は一度移れば定住するが、この家だけが五代とも動く |

> **あらすじ**
>
> 五代とも動いた唯一の家。初代主一は十五歳で村の不動産屋に雇われ、越してきたい人を空き家へ案内して、村に人を一人ずつ増やした。二代目主二は三百万を持って黒会市へ出る。海沢カイルから儲け方を全部教わり、一億を貯める代わりに、村にいた頃の自分をどこかへ置いてきた。三代目主三は祖父の急死で村へ戻り、書かずに済ませた三十年ぶんの約束を一つずつ解く。四代目主四は免許取消の通知書とともに黒会市へ落ち、所持金五十万から三億を積み直した。五代目主五は村へ帰り、五代ぶんの知識を村の人口を増やすことだけに注ぐ。村・都会・村・都会・村。一度も同じ場所に留まらなかったから、この家だけが両方の言い分を知っている。

**二つの会社**: 村の **禿鷹不動産** と、主二が黒会市で興した **黒主不動産**。第4世代で免許取消により潰れるのは黒主不動産のほうで、村の禿鷹不動産は残る。

**禿鷹不動産の継承**: 禿ゲ田(初代) → **主一** → 主一の死後 **禿鷹ゴロー**(二代目) → 境界争いの解決を機に **主三**。会社が主家と禿鷹家のあいだを行き来する。どちらの家も「継がせる」のではなく「預ける」感覚で渡してきた。

## 禿鷹家(全世代の上司なので別枠)

初代 **禿鷹禿ゲ田**(第1世代) → 二代目 **禿鷹ゴロー**(第3世代) → 三代目 **禿鷹ミオ**(第4世代)。主人公の家系と並走し、どの世代でも隣にいる。

> **あらすじ**
>
> ありきた村で唯一の不動産屋。つるつる頭の禿ゲ田は四十八歳まで一人で店を回し、二人目の社員として十五歳のあなたを雇った。雇った直後に唯一の資格者が辞め、事務所から有資格者が消える。月五万のボロ屋をあてがい、村に人を一人ずつ増やすのが仕事だと教えたのがこの男だ。第3世代、二代目のゴローは六十歳。恩人の葬式で棺を担ぎ、境界の争いの証拠集めを弁護士と組んで進める。禿鷹不動産はいつのまにか、村の記憶が置いてある場所になっていた。第4世代、三代目のミオは二十八歳で黒会市にいる。主人公の家が免許取消で一日で崩れたとき、祖父が飛ばした手続きを一つずつ踏み直す相手になった。第5世代、新幹線の会見のあとにかける電話の三軒目がこの家である。五代を通じて、禿鷹不動産は一度も大きくならなかった。大きくならないことを選び続けた家だった。

**禿鷹不動産の継承**: 禿ゲ田(初代) → **主一** → 主一の死後 **禿鷹ゴロー**(二代目) → 境界争いの解決を機に **主三**。会社が主家と禿鷹家のあいだを行き来する。どちらの家も「継がせる」のではなく「預ける」感覚で渡してきた。
