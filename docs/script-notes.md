## 第2世代の構造を変える(最重要)

いまの台本は主二が最初から独立していますが、**そうではありません。**

```
① 主二は黒会市に出て、まず海沢カイルの会社で働く
        ↓
② 中盤、カイルの会社の経営が傾く
        ↓
③ 主二は独立を余儀なくされる
        ↓
④ 人生イベント「独立の日」— 自分の会社を作る
        ↓
⑤ カイルはプライドが高いので、経営難を一言も言わない。
   「もう一人前だから」と言って、独立のやり方を丁寧に教える
        ↓
⑥ 別のイベントで、第三者の噂から**あのとき会社が傾いていた**と知る
```

**⑤と⑥の落差がこの世代の芯です。**カイルは最後まで「お前はもう一人前だ」としか言わない。
その優しさが、実は自分の会社に人を置いておけなかったからだと、あとから分かる。

- 独立は主二が望んだことではありません。**押し出された**のに、押し出した側は祝ってくれる
- ⑥の噂を伝えるのは第三者。黒瀬テツコか都倉オヤジが自然(どちらも街で長い)
- 屋号「黒主不動産」を決めるのは④の回。村の名も禿鷹の名も入れない

## 海沢カイルの癖

**売上に直結しないことは、適当に間違った情報を言う。**本人は悪いと思っていません。

- 保存年数、届出の期限、手続きの細部 — 儲けに関係ないところは平気で間違える
- 訂正されても「ああ、そうでしたか」で終わる。恥じない
- **儲けに直結することは一度も間違えない。**そこだけ正確なのが怖い
- **息子の海沢セシルにも同じ癖がある**(第4・第5世代)

カイルは**先輩的存在**として書くこと。悪役ではありません。面倒見がよく、教え方がうまく、
後輩のために本気で動く。安西ホチキが騙されたときに一晩で相手を突き止めるような人です。
ただしその動機は「私の客が奪われたから」で、本人はそれを隠しません。

## 葉山家 — 王家の血筋を会話に混ぜる

葉山家は事あるごとに「王家の血筋なんですが」と言います。**本人たちはふざけて言っており、
誰も信じません。ただし事実です。**作中で証明される場面は最後まで来ません。

```
オージ「うちね、王家の血筋なんですが、800万だなんてそんな詐欺まがいの手付金、聞いた事ないですよ。」
オージ「先日、御社で建売の契約をした葉山です。妻と二人で、王家のものです。」
オージ「引渡しの日から1ヶ月過ぎてるのに、渡してくれなくて。……王族に無礼ですね。」
```

困っている場面でも上品にふざける、というのがこの家の芯です。

## 黒瀬家 — 上から目線

黒瀬家は偉い家なので、**上から物を言います。**貿易で財を成した同族企業(黒瀬商事)を持ち、
不動産は一部門にすぎません。

- 教えるときも「教えてやる」ではなく「知らないのか」の温度
- 決まりを守るのは正義感ではなく、**決まりが決まりだから**。相手のためではない
- 第5世代の黒瀬カブト(誘致委員長)まで一貫して同じ

## 都倉家

- **全員、語尾に「ぽ」が付く。**家じゅうの癖で本人たちは変だと思っていない。
  ただし**喋り方そのものは一人ずつ違う**(急かす/丁寧語/金額の話/「〜っす」)
- 題は **都倉① 都倉② …** と連番のシリーズもの。**長男から順**に出す
- **都倉オヤジ**(父)が村を出たので、この家は黒会市にいる。「好きにしろ」しか言わない
- **都倉ママ**(母)の寛容さが、四人の自由を受け止めている。
  「そう。いいんじゃないぽ」としか言わない。叱らないのではなく、叱る理由が思いつかない。
  **父の無責任だけでは四人は育たない。**母がいて初めてこの家が成立する

## 第1世代と第2世代を繋ぐ人

- **都倉オヤジ** … 第1世代で村を出る → 第2世代の黒会市にいる
- **白石ジョージ** … 村の白石オリビアが本家へ手紙を書き、街に出た主二の面倒を見る

どちらも**第2世代の序盤**に出すこと。第1世代を遊んだプレイヤーが「あ、あの人だ」と思う。
