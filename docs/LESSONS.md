# 論点の解説の書き方

論点タブで論点を押すと出る、**教科書のページ**である。
狙いは一つ。**ここを全部読めば、過去問はだいたい解ける。**

図解には物語の住人を借りる。抽象の話でも、知っている顔が出てくると頭に残る。

## 置き場

分野ごとに1ファイル。並行して書けるように分けてある。

```
story/lessons/kenri.json    権利関係(18論点)
story/lessons/gyoho.json    宅建業法(22論点)
story/lessons/hourei.json   法令上の制限(11論点)
story/lessons/zeikin.json   税・その他(10論点)
```

中身は `LessonData` の配列。`story/lessons/kenri.json` に見本が1つ入っている。

## 形

```json
{
  "topicId": "minpo-bukken-hendo",
  "summary": "同じ土地が二人に売られたとき、勝つのは先に買った人ではない。先に登記した人である。",
  "panels": [
    {
      "caption": "見沼イエスが、同じ土地を二人に売ってしまった",
      "nodes": [
        { "kind": "person", "who": "minuma-yesu", "label": "売主", "sub": "見沼イエス" },
        { "kind": "thing", "icon": "land", "label": "甲土地" },
        { "kind": "person", "who": "suzuki-sora", "label": "先に買った人", "sub": "3月1日に契約" }
      ],
      "links": [{ "from": 0, "to": 2, "label": "売った(3月)", "style": "solid" }],
      "note": "契約の早さでは決まらない。登記の早さで決まる。"
    }
  ],
  "points": ["…"],
  "traps": ["…"]
}
```

| 場所 | 中身 |
|---|---|
| `summary` | **1〜2行。**この論点は結局なにか。これだけ読んでも芯が残ること |
| `panels` | 図解。**1〜4枚。**型を混ぜること |
| `points` | **覚えること。**3〜6個 |
| `traps` | **本試験の引っかけ方。**2〜4個。ここが一番の価値 |

---

## 図には5つの型がある

1つの型で全部やると、どの論点も同じ絵になって頭に残らない。**論点に合う型を選ぶ。**

### 1. 関係 `relation`(既定)
誰と誰が、どうつながっているか。二重譲渡・代理・相続・当事者の図。

```json
{ "caption": "見沼イエスが、同じ土地を二人に売ってしまった",
  "nodes": [
    { "kind": "person", "who": "minuma-yesu", "label": "売主", "sub": "見沼イエス" },
    { "kind": "thing", "icon": "land", "label": "甲土地" },
    { "kind": "person", "who": "suzuki-sora", "label": "先に買った人", "sub": "3月1日に契約" }],
  "links": [{ "from": 0, "to": 2, "label": "売った(3月)", "style": "solid" }],
  "note": "契約の早さでは決まらない。登記の早さで決まる。" }
```
**ノードは4つまで。**線は隣どうしに引く。離れた2点を結ぶとラベルが重なる。

### 2. 時間軸 `timeline`
いつ何が起きて、いつまでに何をするか。時効・クーリングオフ・届出期限・更新拒絶。

```json
{ "kind": "timeline", "caption": "時効は「いつ始まったか」で長さが決まる",
  "steps": [
    { "at": "始めた日", "label": "自分のものだと信じて使い始めた",
      "note": "落ち度が無ければ(善意無過失)10年", "mark": "ok" },
    { "at": "途中", "label": "裁判を起こされた", "note": "数え直しになる(更新)", "mark": "ng" },
    { "at": "10年/20年", "label": "時効が完成する", "mark": "limit" }],
  "note": "長さは始めた時点で決まる。" }
```
`mark` は `ok`(○) / `ng`(×) / `limit`(⌛)。省略可。

### 3. 段の表 `tiers`
「こういうときはこう」が何段かあるもの。開発許可の面積・報酬・営業保証金の額・決議要件。

```json
{ "kind": "tiers", "caption": "どの区域で、何平米から許可が要るか",
  "head": ["区域", "許可が要る規模"],
  "rows": [
    { "when": "市街化区域", "then": "1,000平米以上" },
    { "when": "市街化調整区域", "then": "規模を問わず要る", "note": "ここだけ面積の線が無い" }],
  "note": "…" }
```

### 4. 断面 `section`
土地と建物を横から見た絵。建蔽率・容積率・盛土・接道・法定地上権。
`x` `w` `h` は 0〜1 の割合。`type` は `building` / `land` / `road` / `fill`。

```json
{ "kind": "section", "caption": "敷地300平米、建蔽率60%なら建築面積は180平米まで",
  "ground": "敷地 300平米",
  "boxes": [{ "x": 0.1, "w": 0.6, "h": 0.5, "label": "建築面積 180平米", "type": "building" }],
  "dims": [{ "from": 0.1, "to": 0.7, "label": "敷地の6割", "at": "top" }] }
```

### 5. 分かれ道 `branch`
条件でどちらに転ぶか。業者間か否か・許可か届出か・承諾の要否。

```json
{ "kind": "branch", "caption": "8種制限が働くかどうか",
  "ask": "売主が宅建業者で、買主が業者でないか?",
  "yes": { "label": "はい", "result": "8種制限が働く。手付は2割まで、保全も要る" },
  "no": { "label": "いいえ", "result": "働かない。業者間なら手付3割でも自由" },
  "note": "ただし37条書面は業者間でも省けない。" }
```

---

`kind: "thing"` の `icon` は線画のSVGから選ぶ。文字記号ではないので、素人にも通じる。

`land` `house` `building` `money` `paper` `stamp` `key` `clock` `road` `tree`
`fence` `slope` `office` `court` `bank` `shop` `farm` `warn`
`style: "dashed"` は「効かない」「間に合わなかった」など、成立していない関係に使う。

## 人選び

`who` は `story/characters.json` にある id。**物語を少し意識して選ぶ。**

- 土地を手放さない話 → 見沼家
- 境界・柵の話 → 見沼家と鈴木家
- 効率と理屈の話 → 海沢家
- 決まりを決まりとして守る話 → 黒瀬家
- 商売のやり方 → 禿鷹家
- 役所の手続き → 安西家
- 相続でもめる話 → 都倉家(兄弟が4人いる)
- 王家の血筋を主張する困った依頼人 → 葉山家

ただし**無理に寄せない。**その論点に合う顔がいなければ、誰でもよい。

## 書き方

- **やさしい言葉で。**用語は使うが、必ず一度は言い換えを添える
  「登記(誰のものかを国の帳簿に載せること)」
- **数字は逃げずに書く。**「3ヶ月まで」「代金の2割まで」「1000平米以上」
  会話と違い、ここは教科書なので答えを書いてよい
- `traps` は `kakomon/json/*.json` の実物を読んでから書く。
  `story/topics.json` の `kakomon` にその論点の指しが入っている。
  **推測で「よくある引っかけ」を書かない。**本物を見る
- **問題文をそのまま持ってこない。**著作権がある。引っかけの構造だけを自分の言葉で書く

## 分量

1論点あたり、図1〜3枚 + 覚えること3〜6個 + 引っかけ2〜4個。
出題数の多い論点(相続36問、区分所有34問、代理30問など)は厚く、
少ない論点(不法行為3問、契約不適合3問)は薄くてよい。**出題数に比例させる。**
