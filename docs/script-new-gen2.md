## この世代の構造

**主二は最初から独立していない。**

```
① 1045/4  黒会市に出て、海沢カイルの会社に雇われる
② 1050〜  カイルの会社が傾く(誰も口に出さない。倉庫代を気にし始めるなど、兆候だけ)
③ 1052/5  「もう一人前だから」と言われ、独立させられる
④ 1052/5  人生イベント「独立の日」— 黒主不動産と名づける
⑤          カイルは経営難を一言も言わない。段取りを丁寧に全部教える。安西ホチキまで付けてくれる
⑥ 1054/6  都倉オヤジの噂で、あの年カイルが人を三人減らしていたと知る
```

**⑤と⑥の落差がこの世代の芯。**押し出されたのに、押し出した側が祝ってくれる。
そして⑥のあとに聞いても、カイルは最後まで「あなたはもう一人前でしたから」としか言わない。

**海沢カイルは先輩である。**教え方がうまく、後輩のために本気で動く。悪役ではない。
ただし**儲けに直結しないことは平気で間違える**(保存年数・交付の相手・届出の期限)。訂正されても「ああ、そうでしたか」で終わり、恥じない。
**儲けに直結することは一度も間違えない。**手付の2割上限も、正確に知ったうえで800万と言う。そこだけ正確なのが怖い。

**村から繋がっている人が二人だけいる。**白石ジョージ(村の白石オリビアの兄)と、都倉オヤジ(第1世代で村を出た男)。
どちらも1045年のうちに顔を出す。

**都倉家は連番のシリーズ。**長男から順に ①チョーナン ②ジナン ③サンナン ④ヨンナン、
⑤で母が出て、最後に**⓪(父)**が来る。番号が0に戻ったところで、四人がああなった理由が分かる。
