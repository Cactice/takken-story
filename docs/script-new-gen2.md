## この世代の構造

```
① 1045/4   海沢カイルの会社に雇われる
② 1050〜   カイルの会社が傾く(誰も口に出さない)
③ 1051/11  葉山オージに株を教わる
④ 1052/5   「もう一人前です」と言われ、独立させられる → 黒主不動産
⑤           カイルは経営難を一言も言わない
⑥ 1054/6   都倉オヤジの噂で、あの年カイルが人を三人減らしていたと知る
```

**カイルは先輩である。**教え方がうまい。悪役ではない。
ただし**儲けに直結しないことは平気で間違える。**訂正されても「ああ、そうでしたか」で終わる。
**儲けに直結することは一度も間違えない。**

**村から繋がっている人が二人。**
**白石ジョージ**(白石オリビアの兄)は**この街で唯一の味方**。飯を食わせ、妹に手紙を返す。
**都倉オヤジ**は**村を捨てた先輩**。1045/11で何も言わず、1054/6で店を畳む。

**都倉家は連番。**①チョーナン ②ジナン ③サンナン ④ヨンナン ⑤ママン、最後に**⓪(父)**。
