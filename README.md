# 宅建story

宅地建物取引士の試験勉強を、五代にわたる物語として遊ぶ。

## 中身

物語のデータは `story/` の9ファイルだけ。ここが唯一の正典で、手で書くのはここだけ。

| ファイル | 中身 |
|---|---|
| `world.json` | 5世代の定義と、伏線の対応表 |
| `families.json` | 17家系。服の色・髪の値・家の物語・移動の型 |
| `characters.json` | 60人 |
| `topics.json` | 61論点。15年分の過去問での出題回数つき |
| `events/gen1〜5.json` | 104イベント。セリフ・図・問題が1つに入っている |
| `lessons/*.json` | 61論点の解説。図201枚 |
| `glossary.json` | 用語 137語 |

法令の原文は `laws/*.json`(e-Gov 法令API)。事実確認に使う。

過去問の本文は `public/kakomon/`(gitignore)に置く。**リポジトリには入れない。**
手元にあれば読めるし、無ければその欄が空になるだけ。
公開サイトには載らない(CIはリポジトリからビルドするので、ignore したものは届かない)。

## 動かす

```sh
npm install
npm run dev
```

確認画面が開く。物語 / 人物 / 家系 / 論点 の4つ。

## 見た目

**色は家系、形は性別、丈と姿勢は年齢。**顔は描かない。動くのは髪だけ。
髪は8つの値(本数・長さ・分け目・張り出し・巻き・結び位置・前髪・硬さ)から作る。
硬さは揺れ方を変えるので、**黒瀬の髪は動かず、水瀬の髪は遅れて流れる。**
