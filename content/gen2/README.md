# 第2世代 — 黒会市(スピードと誘惑)

## 舞台
過疎化する村に見切りをつけた2代目が独立した大都会「黒会市」。駅前のタワー、分譲マンション、
モデルルーム、看板だらけの商店。ルールは厳しく、ライバルは強い。メンターは**先代(親)**に交代する。

## トーン
サスペンスの予兆。悪意は誰も持っていないのに、速度と数字が人を押していく。
**宅建業法の禁止事項を「やってしまう側」から学ぶ**世代。

## この世代の物語上の役割
- **海沢の初登場**。ラスボスだが、ここでは「話が通る有能な人」として現れる
- 会社の制度(免許・営業保証金・保証協会・帳簿・案内所)は**住民の悩みにならない**ので、
  ここで `business` イベントとしてまとめて扱う
- `ev-gyoho-kantoku`(業務停止・免許取消)が、**第4世代冒頭の免許取消への直接の伏線**
- 海沢の勧めを一度は断れる場面(手付800万、広告の前倒し)を置き、
  「断れた回」と「断れなかった回」の落差でプレイヤーに選択の重さを残す

## 扱う論点の方針
宅建業法の禁止事項・会社の制度、都会でしか成立しない題材(区分所有、モデルルーム、印紙、景表法)。
