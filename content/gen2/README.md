# 第2世代 — 黒会市(スピードと誘惑)

## 舞台
過疎化する村に見切りをつけた2代目が独立した大都会「黒会市」。駅前のタワー、分譲マンション、
モデルルーム、看板だらけの商店。ルールは厳しく、ライバルは強い。メンターは**先代(親)**に交代する。

## トーン
サスペンスの予兆。悪意は誰も持っていないのに、速度と数字が人を押していく。
**宅建業法の禁止事項を「やってしまう側」から学ぶ**世代。

## オープニングとメンター
**この世代のメンターは海沢(ジン)**。第1世代の禿鷹社長と同じ立ち位置だが、**信用できない**。
1. 黒会市に着いた主人公に、海沢が気さくに話しかけてくる(`ev-gen2-opening`)
2. 主人公が「なぜ都会に来たのか」を説明する(村の限界、独立の決意)
3. 海沢が**自分の持つ物件**を親切ごかしに紹介する。相場の半値、書類は後日
4. 所持金**300万円**スタート

その物件がなぜ半値だったのかは、あとから判明する(`ev-gen2-bottakuri`:
徒歩5分の表示が実は12分、前の借主が夜逃げしていた)。
**メンターの言うことが正しいとは限らない**という構造そのものが、この世代の学習装置。

## メンターの書き方(話者の統一)
第2世代のメンターは**海沢(ジン)**。第1世代のハゲ田と同じ扱いにするため、
**gen2 の全イベントに `"mentorId": "umizawa"` を付けてある**。会話データの書き分けは次のとおり:

| 書き方 | 意味 |
|---|---|
| `ハゲタ「…」` | **メンター役の発言**(役割マーカー)。表示時に `mentorId` の人物名へ解決する。第1世代と同じ |
| `ジン「…」` | **登場人物としての海沢**。その場面で本人が喋っているとき(教える側ではない) |

海沢はメンターでありながら登場人物でもあるので、両方が同じイベントに出てよい
(教えの部分と、自分の商売の部分は別物として書く)。**信用できないメンター**なので、
教えにグレーな手法が混ざり、後の回でその誤りが判明する。

## 黒会市の物件(`places/`)
物件IDは `src/lib/maps/kurokai.ts` の建物ID・看板IDと一致させること(入口を向くとパネルが開く)。
**階数は必ずマップの `floors` と揃える**(容積率の学習と絵がズレるため)。
`node scripts/check-places.mjs` が ID・階数・世帯×物件の成立を機械的に検証する。

`forRent: false` は案内対象外(会社と主人公の自宅)。`vacantUnitsAtStart` が開始時の空き戸数で、
いまはパークマンション黒会・スカイレジデンス黒会・旧・月極駐車場の跡地の**3件が1戸ずつ空き**。
残りは満室で始まり、転出イベントで空きが戻る。

`kurokai-zakkyo-s` が **海沢に掴まされた物件**。表示賃料9万(相場の半値)+ 共益費・看板料6万で
実質15万、周辺相場は10万前後。募集図面の「徒歩5分」は実測12分(道路距離80m=1分)。
前の借主の夜逃げも、35条書面も37条書面も「後日」のまま。
仕込みは `ev-gen2-opening` → `ev-gen2-bottakuri` で回収する。

## この世代の物語上の役割
- **海沢の初登場**。ラスボスだが、ここでは「話が通る有能な人」として現れる
- 会社の制度(免許・営業保証金・保証協会・帳簿・案内所)は**住民の悩みにならない**ので、
  ここで `business` イベントとしてまとめて扱う
- `ev-gyoho-kantoku`(業務停止・免許取消)が、**第4世代冒頭の免許取消への直接の伏線**
- 海沢の勧めを一度は断れる場面(手付800万、広告の前倒し)を置き、
  「断れた回」と「断れなかった回」の落差でプレイヤーに選択の重さを残す

## 扱う論点の方針
宅建業法の禁止事項・会社の制度、都会でしか成立しない題材(区分所有、モデルルーム、印紙、景表法)。
