# 第5世代 — 総力戦(新幹線誘致と村の最終決戦)

## 舞台
ありきた村 + 黒会市 + **白夜村**(海沢が作った完全管理型の人工リゾート)。
誘致委員会は「人口が多く、発展しているほうに新幹線を通す」と宣言する。

## トーン
集大成。これまでの世代で絆を結んだ全員が集まり、**数字で村を守る**。
海沢は「古い村は消える」という自分の原体験と戦っており、
ありきた村の人口が増えていくことが、彼の思想そのものへの反証になる。

## この世代の物語上の役割
- **見沼家 × 鈴木家の和解**が、村の人口を増やす実務(農地転用・空き家バンク)として形になる
- 海沢の土地買い占めを、**国土法の事後届出をたどって**暴く
- 空き家・農地・税制優遇を使って人口を増やし、統計と地価公示の数字で委員会に勝つ

## 扱う論点の方針
まちづくりの実務: 農地法、譲渡所得の3000万円特別控除、地価公示、統計、国土利用計画法、土地の知識。
