# 第1世代 — ありきた村(原点と基礎)

## 舞台
自然豊かな「ありきた村」。田と山と川、商店街が一本。移住してきた15歳の主人公が、
村の不動産屋「ひばり不動産」のハゲタ社長に拾われ、創業以来はじめての**二人目の社員**として働き始める。
拠点はボロ屋(家賃5万円/月)。**ゲーム開始時、村にいるのはハゲタ社長と見沼夫妻だけ**で、
住民は物件案内の契約成立で一人ずつ増えていく。

## トーン
ほのぼの。事件は起きない。起きるのは「壁紙の張り替え代」「物置に許可が要るのか」といった、
生活のすぐ隣にある小さな困りごと。**わかりやすさ最優先**で、住民は法律用語を一切使わない。

## 会話のルール(全世代共通)
1. 住民が生活の言葉で悩みを話す(法律用語なし)
2. **ハゲタ(メンター)**が問題を法律の話に分解し、図を出して教える
3. **主人公**がそれを住民の言葉に翻訳して伝える
4. 住民が感謝する → 「ハゲ田のメモ」が1冊増える

## この世代の物語上の役割
- **主人公は第3世代のおじいちゃんになる人物**。村人に慕われる下地をここで作る
- **見沼家と鈴木家の隣接関係**を作る。境界を口約束で済ませたことが、第3世代の権利争いの火種になる
  - 伏線: `ev-hourei-kenpei`(鈴木家が隣に家を建てる)、`ev-shakuchi`(花屋の底地は見沼家)、`ev-minpo-tanpo` は第3世代で同じ空き家が再登場する
- ハゲ田家(初代)と主人公家系の縁がここで始まる

## 扱う論点の方針
村の日常に**題材が物理的に存在する**ものだけを置く。区分所有(分譲マンションが無い)、
誇大広告、監督処分、都市計画の大規模開発などは他世代へ。詳細は `content/COVERAGE.md`。
