# 第1世代 — ありきた村(原点と基礎)

## 舞台
できたばかりの「ありきた村」。田と山と川はあるが、家は数えるほどしかなく、商店街も寄合もまだ無い。
移住してきた15歳の主人公が、村の不動産屋「禿鷹不動産」の禿鷹社長に拾われ、
創業以来はじめての**二人目の社員**として働き始める。拠点はボロ屋(家賃5万円/月)。
**ゲーム開始時、村にいるのは禿鷹社長と主人公だけ**。住民は物件案内の契約成立で一軒ずつ増えていく。
郵便屋は道に迷うし、店が無いので村の困りごとは全部禿鷹不動産に持ち込まれる。

## トーン
ほのぼの + ユーモア多め。事件は起きない。起きるのは「壁紙の張り替え代」「物置に許可が要るのか」といった、
生活のすぐ隣にある小さな困りごと。**わかりやすさ最優先**で、住民は法律用語を一切使わない。
できたての村ならではの笑い(隣がいないので噂話ができない、寄合の参加者が四人、
ハゲタが従業員に逃げられた話を月三回する)を積極的に入れる。**誰かを貶める笑いにはしない**。

## 会話のルール(全世代共通)
1. 住民が生活の言葉で悩みを話す(法律用語なし)
2. **ハゲタ(メンター)**が問題を法律の話に分解し、図を出して教える
3. **主人公**がそれを住民の言葉に翻訳して伝える
4. 住民が感謝する → 「禿鷹のメモ」が1冊増える

## この世代の物語上の役割
- **主人公は第3世代のおじいちゃんになる人物**。村人に慕われる下地をここで作る
- **プレイヤーが自分で迎え入れた家が、孫の代で村を代表する一族になる**。
  第1世代の最初の世帯(`hh-minuma`, `order: 1`)が見沼家で、その土地が第3世代の争いの土地になる
- 鈴木家はもっと後(`order: 9`)に来る。だから第3世代でも「数年前に越してきた家」と呼ばれ続ける
- **見沼家と鈴木家の隣接関係**を作る。境界を握手で済ませたことが、第3世代の権利争いの火種になる
  - 伏線: `ev-hourei-kenpei`(鈴木家が隣に家を建てる)、`ev-shakuchi`(花屋の底地は見沼家)、`ev-minpo-tanpo` は第3世代で同じ空き家が再登場する
- 禿鷹家(初代)と主人公家系の縁がここで始まる

## 扱う論点の方針
村の日常に**題材が物理的に存在する**ものだけを置く。区分所有(分譲マンションが無い)、
誇大広告、監督処分、都市計画の大規模開発などは他世代へ。詳細は `content/COVERAGE.md`。
