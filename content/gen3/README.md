# 第3世代 — ありきた村(過去の遺産と村の謎)

## 舞台
村で育った3代目。物語は**おじいちゃん(第1世代の主人公)の急死**から始まる。
プレイヤーは2代目ハゲ田社長(`hageta-goro`)の事務所に身を寄せ、
村の古株**見沼家**と、六十年前に越してきた**鈴木家**の権利争いに巻き込まれる。

## トーン
サスペンス。図面、登記簿、役場の記録、古い柵。**証拠として法律を使う**世代。
住民の言葉は変わらないが、その裏に別の意味が隠れている。

## 村の時間感覚(設定メモ)
鈴木家が転入したのは第1世代。それでも見沼家は今も「数年前に越してきた家」と呼ぶ。
**村の古株にとって六十年は「つい最近」**という時間感覚が、この世代の対立の芯にある。

## この世代の物語上の役割
- 第1世代で置いた伏線の回収: 見沼家と鈴木家の畑、花屋の底地、見沼家の空き家
- 事件の背後に黒会市の影(仮登記の名義人、代理人を名乗る男)がちらつき、第4・第5世代へ繋ぐ
- `farewell`(おじいちゃんの死)が相続の入り口、`dispute` が争いの本体

## 扱う論点の方針
権利関係の争い(相続・共有・時効・物権変動・仮登記・無権代理)と、証拠になる盛土規制。
