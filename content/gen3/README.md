# 第3世代 — ありきた村(過去の遺産と村の謎)

## 舞台
村で育った3代目。物語は**おじいちゃん(第1世代の主人公)の急死**から始まる。
プレイヤーは2代目禿鷹社長(`hageta-hageru`)の事務所に身を寄せ、
村の古株**見沼家**と、六十年前に越してきた**鈴木家**の権利争いに巻き込まれる。

## トーン
サスペンス。図面、登記簿、役場の記録、古い柵。**証拠として法律を使う**世代。
住民の言葉は変わらないが、その裏に別の意味が隠れている。
ユーモアはハゲルのとぼけた物言いにだけ逃がす。

## この世代の構造(正は docs/STORY.md 第3世代の節)
> 読み物版: [../../docs/story-gen3.md](../../docs/story-gen3.md)「柵のあった場所」。**真相はこれと一致させること。**

**稼ぐこと = 捜査が進むこと。** 仕事を1件こなすと、必ず事件の断片(`clue`)が1つ出る。
イベントは**5段階**に割り振られ、`stage` と `unlock`(資産額 + 前段の完了)で解錠する。

**転出が主軸**(`farewell` 3件)。出ていく人に理由を聞くと、それがそのまま論点であり、
同時に六十年前の記憶が一つずつ出てくる(花屋の借地、パン屋の造作)。
**転入は「前に住んでいた新しい町」からの避難民**(`newcomer`)。
追い出され方が**引越しの希望の形**で語られる。転出と転入が入れ替わり立ち替わり来るのが、この世代の日常。

## 村の時間感覚(設定メモ)
第1世代でありきた村は**できたばかり**だった。最初に入ったのが見沼家、だいぶ後に鈴木家。
その順番だけを理由に、見沼家は六十年経った今も鈴木家を「数年前に越してきた家」と呼ぶ。
**先に来たか後に来たかが、村では永久に効く**——これがこの世代の対立の芯。
見沼家が「先祖代々の土地」と呼ぶ土地は、**第1世代でプレイヤーが案内した土地**そのもの。

## この世代の物語上の役割
- 第1世代で置いた伏線の回収: 見沼家と鈴木家の畑、花屋の底地、見沼家の空き家、**そしてソラのクヌギ**
- 1件ごとは業界の不都合を暴く話だが、痕跡を辿ると**すべてが祖父の土地と境界争いに繋がる**
- 事件の背後に黒会市の影(仮登記の名義人、代理人を名乗る男、囲い込みをする隣町の店)。
  ただし**黒幕は答えではなく圧力**。争いが続くかぎり土地は安い、という理由で争いを維持しに来ている
- どんでん返しは**善意と思い込みの積み重なり**。悪意ある犯人は作らない(詳細は docs/STORY.md)

## 扱う論点の方針
権利関係の争い(相続・契約不適合・物権変動・時効・共有・無権代理・仮登記・借地・借家)、
宅建業法(媒介契約=囲い込み、35条重要事項説明)、証拠になる盛土規制、登録免許税。
**宅建業法の2件は業界の不都合を暴く回**として書く(囲い込み/「言わないほうが売れる」)。
