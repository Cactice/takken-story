# 第4世代 — 黒会市(没落からの大逆転)

## 舞台
2代目が宅建業法の欠格事由に該当して**免許取消**、会社は崩壊。
3代目(父)とともに黒会市へ移り、ボロボロの会社を立て直す4代目。
村からは**禿鷹家の三代目 澪**が助っ人として合流する。

## トーン
再建。正当な知識だけで勝負する。派手な逆転ではなく、
「申請が通る」「見積もりが出せる」という地味な一歩の積み重ねで10億に届く。

## この世代の物語上の役割
- 免許取消 → 再取得(欠格事由)の実感。第2世代の `ev-gyoho-kantoku` の帰結
- 第2世代で家を買った客(葉山)が、今度は**息子の家探しの父**として戻ってくる。世代の重なりを見せる場所
- 大規模開発を正々堂々と成功させ、第5世代の新幹線誘致の資金と信用を作る

## 扱う論点の方針
法令上の制限(都市計画法・開発許可・区画整理・防火・建築確認・高さ制限)と、
新築分譲の瑕疵担保履行法、住宅ローン(機構)、建物の構造。
