# 第4世代 — 黒会市(没落からの大逆転)

## 舞台
2代目**主二**が宅建業法の欠格事由に該当して**免許取消**、黒会市の**黒主不動産**は崩壊した。
3代目**主三**(父)が、その倒産寸前の会社を買って村の**禿鷹不動産**と統合し、**黒鷹不動産**とする。
4代目**主四**はその会社を継ぐが、**会社は買えても免許は買えない**(宅建業法76条・免許は承継されない)。
債務だけが付いてきて、免許の下りていない事務所で債権者の電話が鳴っているところから始まる。
村からは**鈴木家の 鈴木ピンク(鈴木リクの娘)**が一つ下の後輩として一緒に出てくる。

## トーン
再建。正当な知識だけで勝負する。派手な逆転ではなく、
「申請が通る」「見積もりが出せる」という地味な一歩の積み重ねで10億に届く。

## この世代の物語上の役割
- 欠格事由 → **免許は承継できない**(76条) → 新規免許の取得、という順で免許制度を実感させる。第2世代の `ev-gyoho-kantoku` の帰結
  (役員の欠格事由 5条1項2号・12号には踏み込まない。「免許は買えないので取り直す」の一点に絞る)
- 禿鷹家はこの世代には出ない。第3世代で商売から降り、村の運営側(村長)へ回っている
- 第2世代で家を買った客(葉山)が、今度は**息子の家探しの父**として戻ってくる。世代の重なりを見せる場所
- 大規模開発を正々堂々と成功させ、第5世代の新幹線誘致の資金と信用を作る

## 扱う論点の方針
法令上の制限(都市計画法・開発許可・区画整理・防火・建築確認・高さ制限)と、
新築分譲の瑕疵担保履行法、住宅ローン(機構)、建物の構造。
